None network mode:
most isolated a container can be—zero network connectivity.

created NONE network mode:
docker run -dit --name none-net-test --network none alpine sh

(you won’t be able to fetch anything!) so do the nettools: hence copy ping.exe from host machine into container
C:\Users\priya>docker cp "C:\Windows\System32\ping.exe" none-net-test:/usr/bin/ping
Successfully copied 46.6kB to none-net-test:/usr/bin/ping
