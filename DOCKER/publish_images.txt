Push docker images to dockerhub =>hub.docker.com(create an account on this)
1.Create dockerfiles and compose files(if needed)

while pushing to repo ur image must be like : username/imagename

2.Build:
docker build .                            :simple build(gives id of image as sha256:xyz...)
docker build -t <image_name> .            :'.'means current directory(path or URL to the build context)

3.Check:
docker images

4.Tag(adding another tag if image already built):
docker tag <username/image_name> <another_username>/<another_imagename>:<tag>

Tag and build in one command:
docker build -t <dockerhub_username>/<image>:<tag> .

5.Login
docker login    =>Enter username and password/access-token of docker account
or
docker login -u <username>
you can configure the credential store in the Docker configuration file, which is located at $HOME/.docker/config.json on Linux 
or %USERPROFILE%/.docker/config.json on Windows

6.push
docker push <dockerhub_username>/<image>:<tag>

==============================================================
tagging images:
[HOST[:PORT_NUMBER]/]PATH[:TAG]

HOST: The optional registry hostname where the image is located. If not specified, Docker's public registry at docker.io is default.
PORT_NUMBER: The registry port number if a hostname is provided
PATH: The path of the image, consisting of slash-separated components. For Docker Hub, the format follows [NAMESPACE]/REPOSITORY, where namespace is either a user's or organization's name. 
If no namespace is specified, library is used, which is the namespace for Docker Official Images.
TAG: A custom, human-readable identifier that's typically used to identify different versions or variants.'latest' is used by default.

examples:
nginx, equivalent to docker.io/library/nginx:latestst
docker/welcome-to-docker, equivalent to docker.io/docker/welcome-to-docker:latest
ghcr.io/dockersamples/example-voting-app-vote:pr-311: an image from the GitHub Container Registry, dockersamples namespace, example-voting-app-vote image repository, pr-311 tag
