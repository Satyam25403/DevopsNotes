WHAT IS A POD?
A group of containers that share the same network namespace, UTS, and optionally IPC. Same concept as a Kubernetes pod — useful for local K8s development.
POD STRUCTURE
pod commands
$ podman pod create --name mypod -p 8080:80
$ podman run --pod mypod nginx
$ podman run --pod mypod myapp
# export pod as K8s YAML!
$ podman generate kube mypod
Containers in a pod share localhost — talk via 127.0.0.1.
podman generate kube exports your pod as K8s manifests.
