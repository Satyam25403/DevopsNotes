RUN vs CMD vs ENTRYPOINT
ENTRYPOINT + THE POWER COMBO
ENTRYPOINT = FIXED + CMD = ARGS
ENTRYPOINT is the fixed executable. CMD becomes its default arguments.

▶ DEFAULT — ENTRYPOINT + CMD
$ docker run myapp

$ docker run myapp --port 8080
python app.py --port 8080
QUICK CHEATSHEET
RUN
Build time. Installs, compiles, configures. Creates a layer.
CMD
Start time default. Fully replaced by docker run <image> <cmd>.
ENTRYPOINT
Fixed executable. CMD becomes its args. Use --entrypoint to override.
COMBO
ENTRYPOINT = the binary. CMD = default flags. Best for CLI tools.
ENTRYPOINT locks the executable. CMD supplies overridable default args.
Together: docker run myapp --port 8080 just swaps the port, not the binary.
