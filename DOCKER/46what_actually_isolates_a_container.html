⚠ CONTAINER ESCAPE — WHY IT'S POSSIBLE
! Shared kernel → kernel exploit → break out of all namespaces
! --privileged disables almost all isolation
! Mounting /var/run/docker.sock = full host access
🔒 HARDENING AGAINST ESCAPE
✓ Never use --privileged in prod
✓ Drop capabilities: --cap-drop ALL --cap-add NET_BIND_SERVICE
✓ Use --read-only rootfs where possible
✓ Enable seccomp + AppArmor profiles
✓ For true isolation: use gVisor or Kata Containers (VM-backed)
OverlayFS = layered read-only + one writable layer.
Shared kernel = container escape possible. Drop privileges.
