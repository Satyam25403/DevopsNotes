DAEMON DOES 5 THINGS IN ORDER
🔍
1. FIND IMAGE
Checks local cache for nginx:alpine. Already pulled? Use it. Not found? Auto-pull from Hub.
▼
📦
2. CREATE CONTAINER
Adds a thin writable layer on top of the read-only image. Your writes go here. Image untouched.
▼
🔒
3. SET UP NAMESPACES
PID, NET, MNT namespaces applied. Container gets its own process tree + network stack.
▼
🌐
4. WIRE PORT -p 8080:80
iptables rule: traffic on host:8080 → container:80. Your browser can now reach nginx.
▼
🚀
5. START ENTRYPOINT
Runs nginx -g 'daemon off' as PID 1. Container is now LIVE. Flag -d keeps it in background.
-d = detached (background) -p = port map
The returned hash (3a9f1e2c…) is the container ID. Daemon handles everything — CLI just sent the instruction.
