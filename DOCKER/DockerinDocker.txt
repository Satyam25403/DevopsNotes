🧰 How to Use Docker Inside a Docker Container (DinD)
To run Docker commands inside your container, you need to mount the Docker socket from your host. Here's how:
✅ Step 1: Exit your current container
Type exit to return to your host terminal.
✅ Step 2: Run Ubuntu with Docker socket mounted
docker run -it --privileged -v /var/run/docker.sock:/var/run/docker.sock ubuntu bash

This gives your container access to the host's Docker daemon.
🐳 Step 3: Install Docker CLI Inside the Container
Once inside the new container:
apt update
apt install -y docker.io


Now you can run Docker commands like:
docker ps
docker run hello-world
