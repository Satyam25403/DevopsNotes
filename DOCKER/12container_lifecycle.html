FINAL
⚠ docker rm vs docker rm -f
docker rm web — only works if stopped
docker rm -f web — force stops then removes
docker container prune — remove ALL stopped
Image is NOT deleted. Only the container + its writable layer.

docker rm = container gone. Image stays.
The image is the blueprint — it survives. Only the running instance (writable layer + data) is deleted. Use volumes to persist data across rm.
