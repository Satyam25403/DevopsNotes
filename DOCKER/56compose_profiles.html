services:
web: # no profile = always starts
image: myapp:latest

image: postgres:16
pgadmin:
image: dpage/pgadmin4
profiles: [debug] # KEY
mailhog:
image: mailhog/mailhog
profiles: [debug]
jaeger:
image: jaegertracing/all-in-one
profiles: [debug]
THE RULE
Services with no profile always start.
Services with profiles: [x] only start
when --profile x is passed.
MULTIPLE PROFILES
profiles: [debug, monitoring]
Starts if ANY listed profile is active.
One file. Profile-tagged services are invisible by default.
profiles: [debug] is the on/off switch for optional services.
