DOCKERFILE
RECIPE FOR ONE IMAGE
BUILD STEP IMAGE FACTORY
Dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
CMD ["node", "server.js"]
📦 DOCKERFILE = ONE JOB
Define the environment for one container.
Base image → deps → code → start cmd.
Output: a portable image anyone can run.
🚫 WHAT IT CANNOT DO
Link a database container to your app.
Set up networks between services.
Mount volumes across containers.
→ That's Compose's job.
A Dockerfile is a blueprint. It tells Docker HOW to build one image.
Think: recipe card. Not the whole kitchen.

WHAT COMPOSE CREATES
🎼 COMPOSE = ORCHESTRATOR
Run multiple services with one command.
Wire them together on a shared network.
Mount volumes, set env vars, manage order.
Compose references your Dockerfile via `build: .`
It doesn't replace the Dockerfile — it calls it.

TYPICAL PROJECT LAYOUT
📄 DOCKERFILE = "HOW TO COOK ONE DISH"
Ingredients, steps, temperature. One recipe → one result.
📋 COMPOSE = "THE RESTAURANT MENU"
Lists all dishes (services), how they relate, who serves what.
🚀 THE ONE COMMAND TO RULE THEM ALL
docker compose up --build
Builds images via Dockerfiles, starts all containers, wires everything.
Dockerfile defines. Compose orchestrates. Same project, different jobs.
