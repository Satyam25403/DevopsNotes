❌ CLASSIC FAILURE — NO MULTI-PLATFORM BUILD
# Mac dev builds image locally
docker build -t my-app .
# → linux/arm64 image

# CI pulls and runs it
docker run my-app
exec format error 💀
⚠ WHY IT BREAKS
A binary compiled for ARM64 cannot run
on an x86_64 CPU. Different instruction sets.
Docker images are architecture-specific
unless you explicitly build for multiple targets.
💡 THE FIX — buildx + --platform
docker buildx build \
  --platform \
  linux/amd64,linux/arm64 \
  -t my-app --push .
one command → two images → one manifest
arm64 binary + x86 machine = exec format error.

WHAT buildx DOES INTERNALLY
1. Spawns a build container per platform (amd64, arm64)
2. QEMU translates arm64 instructions → runs on x86 host
3. Each platform produces its own image layer set
4. A manifest list wraps both → pushed as one tag
⚠ QEMU IS SLOWER THAN NATIVE
Emulating arm64 on amd64 is 4–10× slower.
For production CI, use native ARM runners
(GitHub has arm64 runners) to avoid this.
QEMU is fine for occasional local builds.
buildx uses QEMU to emulate foreign CPU architectures.
Each platform builds independently → joined in manifest.

THE FULL COMMAND
COMPLETE PATTERN FOR CI/CD
FULL GUIDE CORRECT ✓
COMPLETE buildx COMMAND
docker buildx build \
  --platform linux/amd64,linux/arm64 \
  --tag myuser/my-app:1.0.0 \
  --tag myuser/my-app:latest \
  --push .
--push is required for multi-platform (no local load)
GITHUB ACTIONS — CI PATTERN
- name: Set up buildx
  uses: docker/setup-buildx-action@v3

- name: Build and push
  uses: docker/build-push-action@v5
  with:
    platforms: linux/amd64,linux/arm64
    push: true
    tags: myuser/my-app:1.0.0
⚠ GOTCHAS TO KNOW
✗ --load doesn't work with multi-platform — use --push
✗ Base image must also support your target platforms
! Use --platform=$BUILDPLATFORM in FROM for build tools
! Native runners are faster — GitHub arm64 runners avoid QEMU
DOCKERFILE — NATIVE BUILD TOOLS PATTERN
# use host arch for build stage
FROM --platform=$BUILDPLATFORM \
  node:18 AS builder
RUN npm ci && npm run build

# target arch for runtime stage
FROM node:18-slim
COPY --from=builder /app/dist .
build tools run native → output runs on target ✓
