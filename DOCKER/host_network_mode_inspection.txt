REASON:
🧠 Why WSL Can’t Ping Windows Host
WSL runs inside a virtualized network adapter, which acts like a separate computer on a private subnet (usually 172.x.x.x). Meanwhile, your Windows host resides on your LAN (like 192.168.29.138). Even though they’re tightly linked through localhost and shared filesystems, ICMP (ping) is often blocked or not routed by default between those interfaces.
So even though you can curl services via localhost, pinging 192.168.29.138 directly from WSL might silently fail.

docker run -dit -p 8081:80 --name bridge-app alpine sh
docker exec -it bridge-app sh
apk add --no-cache python3
python3 -m http.server 80

then create a container in host mode let(host-net-app) to hit the exposed port of the container in bridged mode=>
