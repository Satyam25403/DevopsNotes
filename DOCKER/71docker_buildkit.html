CI pipeline — registry cache
$ docker buildx build \
--cache-from type=registry,ref=myrepo/cache \
--cache-to type=registry,ref=myrepo/cache,mode=max \
-t myrepo/app:latest .
# GitHub Actions shorthand
$ docker buildx build \
--cache-from type=gha \
--cache-to type=gha,mode=max \
-t myapp .
mode=max vs mode=min
min: only final stage cached.
max: ALL intermediate stages cached.
Always use max for best CI hit rate.
Without registry cache, every CI run builds from scratch.
--cache-from/to with type=registry or gha: near-instant CI.
