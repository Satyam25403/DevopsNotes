③ COPY DEPS FIRST, CODE SECOND
Copy package.json before source files.
Docker cache: deps only rebuild when lock file changes.
# ✗ cache-busting every change
COPY . .
RUN npm ci
# ✓ cache deps separately
COPY package*.json ./
RUN npm ci --omit=dev
COPY src/ ./src/
These three changes alone drop your image by ~94% and speed up rebuilds.
Layer order is a performance contract, not a style choice.

④ MULTI-STAGE BUILD
Build tools (gcc, npm, git) never reach prod.
Final image only has the runtime artifact.
multi-stage build flow
# Stage 1: build
FROM node:18.20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY src/ ./src/
RUN npm run build
# Stage 2: prod (only the output)
FROM node:18.20-alpine AS prod
COPY --from=builder /app/dist ./dist
⑤ RUN AS NON-ROOT USER
Root in a container = root on host if escaped.
Create a dedicated user, drop privileges before CMD.
# ✗ implicit root — dangerous
CMD ["node", "server.js"]
# ✓ dedicated user
RUN addgroup -S app && adduser -S app -G app
USER app
CMD ["node", "server.js"]
Multi-stage keeps build junk out. Non-root limits blast radius of exploits.
These two changes together are your biggest security wins.

⑥ ADD A HEALTHCHECK
Kubernetes & Swarm restart unhealthy containers.
Without this — they just assume everything is fine.
# ✗ no healthcheck → orchestrator is blind
# ✓ tell the platform you're alive
HEALTHCHECK --interval=30s \
--timeout=5s --retries=3 \
CMD wget -qO- localhost:3000/health || exit 1
⑦ NEVER BAKE SECRETS IN ENV
ENV vars are visible in `docker inspect`.
Use --env-file, Docker Secrets, or runtime injection.
# ✗ baked in — visible in image history!
ENV DB_PASS=s3cr3t
# ✓ inject at runtime
docker run --env-file .env myapp
# or via compose secrets:
secrets: [db_pass]
⑧ HANDLE SIGNALS (EXEC FORM)
Shell form spawns a shell that swallows SIGTERM.
Exec form sends signals directly to your process.
# ✗ shell form — SIGTERM never arrives
CMD node server.js
# ✓ exec form — process gets signal
CMD ["node", "server.js"]
# bonus: use tini for zombie cleanup
RUN apk add --no-cache tini
ENTRYPOINT ["/sbin/tini","--"]
Healthcheck keeps orchestrators informed. Signal handling means clean shutdowns.
Secrets at runtime, never baked in. Rule of thumb: if it can rotate, don't bake it.
