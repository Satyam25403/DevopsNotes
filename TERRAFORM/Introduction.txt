TERRAFORM: An IaC tool, uses configuration files to provision the infrastructure
Not limited to one cloud provider...
- An open-source IaC tool by HashiCorp
- How it works: Uses configuration files written in HCL (HashiCorp Configuration Language)
- What it does: Provisions, updates, and manages infrastructure across multiple platforms

🌐 Multi-Cloud Power
Terraform is cloud-agnostic, meaning it can manage resources across:
- AWS: EC2, S3, IAM, VPC, etc.
- Azure: VMs, Resource Groups, Networking
- Google Cloud: GKE, Cloud Storage, Compute Engine
- Others: Kubernetes, VMware, OpenStack, even on-prem
You define your infrastructure once, and Terraform handles the rest—across clouds, consistently.

🧾 Example: Provision an EC2 Instance on AWS
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "web" {
  ami           = "ami-0c94855ba95c71c99"
  instance_type = "t2.micro"
}

Run:
terraform init
terraform apply

Boom—your EC2 instance is live.

Setting up a provider:(we will stick on to aws)

convention: start with main.tf

terraform{
  required_providers{
    aws ={
      source = "hashicorp/aws"
      version = "-> 4.0"
    }
  }
}

provider "aws" {
  region = "ap-south-1"
  access_key = <access_key>
  secret_key = <secret_key>
}

before running anything, u need to initialize a terraform directory=> make a directory and inside(main.tf should be inside this)...then do these
>terraform init         =>.terraform folder and .terraform.lock.hcl
never manually change these 




now we have a provider, now provision an s3 resource:
resource "aws_s3_bucket" <some_name>{
  bucket = <bucket_name>
  acl = "private"
  tags = {
    "name" : "value"
  }
}

NOTE:<some_name> is not the resource actual name, instead it is the name used by terraform to distinguish the resources within it.
command to provision: (run in that directory)
>terraform apply        =>once u run this u will see some .tfstate file
dont change the contents of the file -> it defines the current state of the architecture

to destroy resources:
>terraform destroy
