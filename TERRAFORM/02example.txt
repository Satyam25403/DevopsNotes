Helm provider : helps us to use our kubernetes yaml files directly without need of writing the file in resource body of .tf files

The Helm provider in Terraform lets you deploy Kubernetes applications using Helm charts, so you don’t have to manually rewrite your 
YAML files into Terraform resource blocks. It’s a powerful bridge between Helm’s packaging system and Terraform’s infrastructure-as-code 
workflow.

🚀 What the Helm Provider Does
- Uses Helm charts directly (from public or private repositories of artifact hub)
Artifact Hub is a central catalog for Helm charts, including those from Bitnami, 
Prometheus, Grafana, and many others. You can use charts from Artifact Hub by referencing their repository URLs or OCI registry paths.
- Manages Helm releases declaratively with version control
- Supports values overrides via set blocks or values.yaml files

main.tf
provider "helm" {
  kubernetes {
    config_path = "~/.kube/config"
    config_context = <some_cluster>
  }
}

resource "helm_release" "nginx" {
  name       = "nginx"
  repository = "https://charts.bitnami.com/bitnami"           
  chart      = "nginx"
  version    = "13.2.24"

  set {
    name  = "service.type"
    value = "LoadBalancer"
  }
}


This deploys the Bitnami NGINX chart to your cluster—no need to copy-paste Kubernetes YAML.

🔧 Bonus Features
- Use values = [file("values.yaml")] to load custom config
- Supports OCI registries and private chart repositories
- Works seamlessly with Terraform’s dependency graph

---

If you have a Helm chart stored locally in a folder like ./charts, you can deploy it using the 
Terraform Helm provider without needing a remote repository. Here's a clean example:

📁 Project Structure
terraform/
├── main.tf
└── charts/
    └── mychart/
        ├── Chart.yaml
        ├── templates/
        └── values.yaml

🧾 main.tf 
provider "helm" {
  kubernetes {
    config_path = "~/.kube/config"
  }
}

resource "helm_release" "local_chart" {
  name       = "my-local-app"
  chart      = "./charts/mychart"
  namespace  = "default"

  values = [file("./charts/mychart/values.yaml")]
}

✅ What This Does
- Deploys the Helm chart from your local ./charts/mychart directory
- Uses the values.yaml file to configure the release


terraform apply -auto-approve           =>applies the new configuration for Infra
