Minikube: allows to create kubernetes clusters locally but can be resource intensive(might slow down machine)
alternative can be kind but with lesser features
 Minikube
- Purpose: Spins up a full Kubernetes cluster locally.
- Pros:
- Supports multiple drivers (Docker, VirtualBox, Hyper-V, etc.)
- Includes Kubernetes Dashboard, Ingress, LoadBalancer emulation

create a cluster => minikube start --nodes=<number_of_nodes> -p <cluster_name>
ex: minikube start --nodes=3 -p dev-cluster
view all clusters/profiles => minikube profile list
switch between clusters/profiles => minikube profile <dev-cluster>
stop the cluster => minikube stop -p dev-cluster


minikube start      =>create a cluster
minikube dashboard  =>open minikube dashboard locally
minikube stop     =>pause the cluster
minikube delete   =>wipe the cluster completely
minikube service <servicename:frontend>   =>access a service(opens in local env in browser automatically)


k8s Dashboard with help of minikube:
minikube dashboard  => command to open ur local dashboard(GUI)
- Opens the official Kubernetes Dashboard in your default web browser
- Gives you a visual interface to manage pods, deployments, services, and more
- Automatically sets up a proxy so you can interact with the cluster securely
If you're running this in a headless environment (like a remote server or WSL2), you can still access the dashboard by running:
minikube dashboard --url
