LDAP — DEFENCE
LDAPS · DISABLE ANON · AUDIT QUERIES
DEFENCE HARDEN AD
① ENFORCE LDAPS (PORT 636) — TLS ONLY
plain LDAP (389) transmits credentials in cleartext.
anyone on the network can sniff bind credentials.
enforce LDAPS: deploy AD CS, configure channel binding.
# GPO: enforce LDAP channel binding + signing
Domain Controller: LDAP server channel binding token requirements
→ set to "Always"
→ LDAP server signing requirements: "Require signing"
② DISABLE ANONYMOUS BIND
anonymous LDAP allows unauthenticated queries — no account needed at all.
disable it: set dsHeuristics bit 7 = 0 on the directory service object.
$ Set-ADObject -Identity "CN=Directory Service,…" \
-Replace @{dsHeuristics="0000000000000000000000000200000"}
③ AUDIT LDAP QUERY LOGS — DETECT BULK ENUM
enable "Directory Service Access" auditing.
alert on: >500 LDAP queries/min from one source.
baseline normal query rate · alert on deviation.
# Event ID 1644 — expensive/slow LDAP query logged
# Event ID 4662 — object access on AD objects
alert rule: count(1644) > 200 per 60s from same IP → page
④ PROTECT KERBEROASTABLE ACCOUNTS
service account passwords ≥ 25 chars (impractical to crack).
use Managed Service Accounts (MSAs) — auto 240-char passwords.
enable AES-only encryption on SPN accounts — RC4 hashes are faster to crack.
