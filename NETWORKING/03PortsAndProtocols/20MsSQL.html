HARDENING & REMEDIATION
STEP 3 — FIX IT REMEDIATION
Five changes that break this attack chain permanently.
# Disable xp_cmdshell
EXEC sp_configure 'xp_cmdshell', 0;
RECONFIGURE;
EXEC sp_configure 'show advanced options', 0;
RECONFIGURE;
# Disable sa account entirely
ALTER LOGIN sa DISABLE;
ALTER LOGIN sa WITH PASSWORD = 'C0mpl3x!R@nd0m';
# Switch to Windows Authentication mode
# Least-privilege app account
CREATE LOGIN appuser WITH PASSWORD = '...';
CREATE USER appuser FOR LOGIN appuser;
GRANT SELECT, INSERT, UPDATE, DELETE
  ON SCHEMA::dbo TO appuser;
# No EXECUTE, no sysadmin, no ALTER
# Block 1433 at host firewall (Windows)
netsh advfirewall firewall add rule
  name="Block MSSQL external"
  protocol=TCP localport=1433 dir=in
  action=block remoteip=!LAN_SUBNET

SECURITY RULE
Disable sa and use Windows Authentication. Block 1433 at the network perimeter — it should never be reachable from the internet. xp_cmdshell off by default; keep advanced options locked too.
