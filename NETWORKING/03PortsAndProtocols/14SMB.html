ETERNALBLUE UNAUTHENTICATED
CVE / MS17-010: SMBv1 BUFFER OVERFLOW
SMBv1 transaction handler incorrectly
calculates buffer sizes when handling
TRANSACTION2 requests.
Result: heap overflow → shellcode execution
as NT AUTHORITY\SYSTEM.

Windows auth protocol. Server sends
challenge → client hashes password
with challenge → server verifies.
Key flaw: hash can be relayed without cracking.

THE KEY INSIGHT
NTLM doesn't use the plaintext password —
it uses the NT hash (MD4 of UTF-16 password).
If you have the hash, you are authenticated.
No cracking needed.

WHAT SMB SIGNING DOES
Every SMB packet is digitally signed.
Relay attacker cannot forge the signature
→ relayed auth is rejected by target.
Also prevents tampering of file content in transit.
