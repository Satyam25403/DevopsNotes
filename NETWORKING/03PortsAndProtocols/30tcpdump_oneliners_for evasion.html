CLEARTEXT CAPTURE FTP / TELNET
FTP and Telnet transmit credentials in cleartext. One command captures them all.
CAPTURE FTP SESSION (PORT 21)
root@box:~# tcpdump -i eth0 -A port 21
tcpdump: verbose output suppressed, use -v for full
listening on eth0, link-type EN10MB (Ethernet)
10:42:01.123 IP 10.0.0.5.52341 > 10.0.0.1.21
E..<..@.@..........USER admin
10:42:01.456 IP 10.0.0.5.52341 > 10.0.0.1.21
E..<..@.@..........PASS s3cr3tP@ss!
# Username and password captured in plaintext ^^^
CAPTURE TELNET SESSION (PORT 23)
root@box:~# tcpdump -i eth0 -A port 23
10:43:12.001 IP 192.168.1.10 > 192.168.1.1
login: root
Password: admin123
# Full Telnet session in cleartext — every keystroke
GREP FOR CREDS ACROSS ALL CLEARTEXT
root@box:~# tcpdump -A -s0 port 21 or port 23 or port 80 \
  | egrep -i 'pass=|password=|user=|login='

SCAN DETECTION — CATCH THE RECON
SYN SCAN DETECTION TCP FLAGS
nmap SYN scan sends SYN-only packets to every port. tcpdump can catch it in real time.
DETECT ALL SYN PACKETS (PORT SCANS)
root@box:~# tcpdump -i eth0 'tcp[tcpflags] & tcp-syn != 0'
listening on eth0 ...
10:51:01 IP 10.0.0.99.54321 > 10.0.0.1.22: Flags [S]
10:51:01 IP 10.0.0.99.54322 > 10.0.0.1.80: Flags [S]
10:51:01 IP 10.0.0.99.54323 > 10.0.0.1.443: Flags [S]
10:51:01 IP 10.0.0.99.54324 > 10.0.0.1.3306: Flags [S]
10:51:01 IP 10.0.0.99.54325 > 10.0.0.1.8080: Flags [S]
# Same source, many ports, no SYN-ACK = nmap -sS scan
FILTER OUT LEGITIMATE HANDSHAKES
root@box:~# tcpdump -i eth0 \
  'tcp[tcpflags] == tcp-syn'
# tcp-syn ONLY (no ACK bit) = half-open scan packets
# Legitimate clients send SYN then SYN+ACK — this is stealth
TCP FLAG REFERENCE
[S]
SYN — connection initiation. Scanner sends thousands of these.
[S.]
SYN-ACK — server reply. Confirms port is open.
[R]
RST — port closed. Scanner gets this back for closed ports.
[F]
FIN — used in FIN scan to bypass some firewall rules.
tcp[tcpflags] & tcp-syn != 0 captures every SYN. Same source + many ports = scan.
SYN-only (no ACK) is nmap -sS stealth scan. Visible to tcpdump, invisible to some firewalls.

TCPDUMP ONE-LINERS
SAVE PCAP & FULL CHEATSHEET
-w / -r PCAP FILES CHEATSHEET
Capture to file, analyse later in Wireshark. Essential for IR and forensics.
# Capture to pcap file for Wireshark
tcpdump -i eth0 -w capture.pcap
# Ctrl+C to stop. File grows until stopped.
# Read pcap back (offline analysis)
tcpdump -r capture.pcap -A port 21
tcpdump -r capture.pcap | egrep -i 'pass='
# Ring buffer: 10 files of 100MB each
tcpdump -i eth0 -w cap.pcap -W 10 -C 100
# Overwrites oldest when full — continuous capture
QUICK REFERENCE
# FTP cred hunt
tcpdump -A -s0 port 21 | grep -i 'PASS'
# HTTP POST bodies (login forms)
tcpdump -A -s0 port 80 | grep -i 'pass=\|user='
# SYN scan detection
tcpdump 'tcp[tcpflags] == tcp-syn'
# Capture specific host only
tcpdump -i eth0 host 10.0.0.5 -w host.pcap
# DNS queries (spot exfil / C2 domains)
tcpdump -i eth0 port 53 -A | grep -i 'A?'
DEFENCE TIP
Run tcpdump on your own servers periodically. If you see FTP or Telnet — kill them. If you see DNS queries to random domains from an app server — investigate immediately. Packet capture doesn't lie.
-w saves pcap for Wireshark. -r reads offline. -C/-W for ring buffer rotation.
tcpdump is on every Linux server. You don't need Wireshark to find cleartext creds.
