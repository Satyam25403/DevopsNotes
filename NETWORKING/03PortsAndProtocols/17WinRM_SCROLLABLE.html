🔒 DISABLE 5985 — FORCE HTTPS (5986)
# Disable HTTP listener
winrm delete winrm/config/listener?Address=*+Transport=HTTP
# Create HTTPS listener (cert thumbprint req)
winrm create winrm/config/listener?Address=*+Transport=HTTPS @{Hostname="srv";CertificateThumbprint="THUMB"}
Eliminates cleartext SOAP traffic. Cannot sniff credentials or commands from network captures.
🚧 RESTRICT TO MANAGEMENT SUBNET
# Windows Firewall — allowlist src IPs
New-NetFirewallRule -Name "WinRM-Mgmt" -Protocol TCP
  -LocalPort 5985,5986 -RemoteAddress 10.0.100.0/24
  -Action Allow
Only jump box / management VLAN IPs can reach WinRM. External attacker blocked at firewall even with valid creds.
🔑 BLOCK NTLM — REQUIRE KERBEROS
• GPO: Network Security: Restrict NTLM → Deny all accounts
• Protected Users security group — blocks NTLM for privileged accounts
• Kills evil-winrm -H hash attack — Kerberos can't be passed-the-hash
AUDIT + VERIFY IN 2 COMMANDS
winrm enumerate winrm/config/listener # see open listeners
Get-WSManInstance winrm/config/service # auth config

Auth NTLM=true in domain → block via GPO
