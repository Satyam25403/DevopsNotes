HOW BBR IS DIFFERENT
Tracks: BtlBw (bottleneck bandwidth) + RTprop
Pacing rate = BtlBw · gain
cwnd = BtlBw × RTprop (BDP)
Doesn't need loss to probe — uses RTT signals.
Periodically probes for more BW then backs off.
WHERE BBR WINS
High BDP links (100ms+ RTT, 1Gbps): fully utilizes pipe
Lossy wireless: ignores random loss, only reacts to delay
GCP/YouTube: 4× higher throughput vs CUBIC on same links
Warning: BBR v1 can be aggressive with other CUBIC flows
