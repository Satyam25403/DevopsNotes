MULTI-ACCESS SEGMENT ELECTION
On Ethernet segments, without DR/BDR
N² adjacencies flood the segment.
DR/BDR reduces this to N adjacencies.

⚠ THE 10G PROBLEM:
Default ref-bw = 100 Mbps.
100Mbps: cost = 100/100 = 1
1G:     cost = 100/1000 = 0.1 → rounds to 1
10G:    cost = 100/10000 = 0.01 → rounds to 1
OSPF treats 100M = 1G = 10G!
FIX — SET HIGHER REFERENCE BANDWIDTH:
! Set ref-bw to 10G on all routers
router ospf 1
 auto-cost reference-bandwidth 10000

! Now:
! 100M → cost 100
! 1G  → cost 10
! 10G → cost 1
! Must match on ALL routers!
Or override per-interface: ip ospf cost <n>
Useful when connected to mismatched vendor gear.
Cost = 10⁸ ÷ bw. 10G and 100M look identical!

NO AUTH → LSA INJECTION ATTACK
OSPF SECURITY DANGER
OSPF has no authentication by default.
Any router on the segment can
inject fake LSAs and corrupt the LSDB.

WHAT AN ATTACKER CAN DO:
• Blackhole traffic → fake low-cost route to null
• MitM all traffic → route all hosts via attacker
• Partition the network → inject costs=65535
• Replay old LSAs → confuse sequence numbers
FIX — ENABLE SHA-256 AUTHENTICATION:
! Define key chain

 key 1
  key-string S3cur3P@ssw0rd!
  cryptographic-algorithm hmac-sha-256

! Apply to interface
