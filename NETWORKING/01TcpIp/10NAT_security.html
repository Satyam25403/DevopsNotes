THE BREAKAGE CRITICAL
✗ IPsec AH — AUTHENTICATION HEADER
IP HEADER
src:10.0.0.5

AH CHECK
FAILS ✗
AH signs the entire IP header including src address.
NAT changes src IP → AH signature breaks → DROP.
Fix: use ESP (tunnel mode). NAT-T port 4500.
✗ P2P / VOIP / SIP PROTOCOLS
SIP embeds IP:port inside payload (not header).
NAT rewrites header but not payload content.
Remote end tries 10.0.0.5:5060 = unreachable.
Fix: ALG (Application Layer Gateway) or STUN.
SIP H.323 FTP active BitTorrent
✗ END-TO-END ARCHITECTURE BROKEN
Internet was designed host ↔ host end-to-end.
NAT inserts a stateful middlebox that breaks this.
Servers behind NAT CANNOT accept inbound connections.
Hosting anything requires workarounds (port forward, VPN).
