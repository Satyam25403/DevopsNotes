FAILS ✗
AH signs the entire IP header including src address.
NAT changes src IP → AH signature breaks → DROP.
Fix: use ESP (tunnel mode) not AH. NAT-T port 4500.
✗ P2P / VOIP / SIP PROTOCOLS
SIP embeds IP:port inside payload (not header).
NAT rewrites header but not payload content.
Remote end tries to reach 10.0.0.5:5060 = dead.
Fix: ALG (Application Layer Gateway) or STUN.
SIP H.323 FTP active mode BitTorrent
✗ END-TO-END ARCHITECTURE BROKEN
Internet was designed end-to-end: host ↔ host.
NAT inserts a stateful middlebox that breaks this.
Result: servers behind NAT CANNOT accept inbound.
Hosting anything behind NAT requires workarounds.
