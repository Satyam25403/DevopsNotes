ORIGIN SHIELDING — iptables
# ACCEPT only Cloudflare IP ranges
iptables -A INPUT -s 103.21.244.0/22 -j ACCEPT
iptables -A INPUT -s 103.22.200.0/22 -j ACCEPT
# ... (all CDN ranges)
# DROP everything else on port 443
iptables -A INPUT -p tcp --dport 443 -j DROP
Direct IP scan of your origin → rejected.
Only CDN edge IPs can reach your server.
DDoS scrubbing → WAF → cache check → origin. Attacker never reaches your DB.
Whitelist only CDN IP ranges in iptables. Your origin becomes invisible.
