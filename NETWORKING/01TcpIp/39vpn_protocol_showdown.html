✓ GOOD
Flexible cipher suite. TCP mode survives restrictive firewalls (port 443). Battle-tested since 2001.
✗ BAD
Userspace = every packet crosses kernel/userspace boundary. ~100k LOC. TLS renegotiation complexity. Daemon restarts break sessions.

IPSEC IKEv2 — THE ENTERPRISE STANDARD
IPSEC IKEv2
IKEv2 NEGOTIATION
IKE_SA_INIT
Diffie-Hellman key exchange · cipher negotiation
Nonces exchanged · IKE SA established
↓
IKE_AUTH
Identity auth (certs / PSK) · CHILD_SA created
ESP/AH tunnel negotiated and keyed
↓
DATA PLANE (ESP)
AES-GCM / ChaCha20 · kernel-native · fast
✓ GOOD
Kernel-native ESP → near line-speed. Native on iOS/Android/Windows. MOBIKE handles roaming. Certificate auth.
✗ BAD
Config complexity is high. IKEv1 is broken — never use it. PSK misconfig is common CVE source. 500+ IETF RFCs.
⚠ COMMON MISCONFIG
ike=3des-sha1-modp1024 ! ← broken
ike=aes256gcm16-sha2_256-ecp384 ← safe
# Logjam / FREAK if DH < 2048
IPsec: fast kernel path but complex IKEv2 setup.
Misconfig is the main risk — audit your proposals.
