DHCP ATTACKS
STARVATION · ROGUE SERVER · SNOOPING
THREAT MODEL ATTACKS
✗ DHCP STARVATION
Attacker sends thousands of DISCOVERs with random MAC addresses.
Server exhausts its pool — legit clients get no IP → DoS.
Defense: port security, limit MACs per switch port.
DoS random MACs port security fix
✗ ROGUE DHCP SERVER (MitM)
Attacker runs their own DHCP server on the LAN.
Responds to DISCOVERs faster than legit server.
Hands out attacker's IP as gateway → all traffic intercepted.
Defense: DHCP Snooping on managed switches.
MitM fake GW DHCP snooping
✓ DHCP SNOOPING (DEFENSE)
Switch feature: marks ports as trusted or untrusted.
Untrusted ports: DHCP OFFERs are dropped.
Only the designated server port can send offers.
Also blocks starvation attacks per-port.
ip dhcp snooping
ip dhcp snooping vlan 10
interface gi0/1 → ip dhcp snooping trust
