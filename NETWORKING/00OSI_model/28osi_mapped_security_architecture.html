L1 PHYSICAL + L2 DATA LINK
L1 + L2 HARDWARE
IF YOU CAN TOUCH IT, YOU OWN IT — DEFEND THE PHYSICAL FIRST
🔒
L1 — PHYSICAL ACCESS CONTROL
Server rooms behind keycards + biometrics. CCTV on all racks. Disable unused USB ports (prevent rubber-ducky attacks). Use fibre over copper where possible — fibre can't be tapped by induction.
KEYCARD USB DISABLED FIBRE
🔐
L2 — 802.1X PORT AUTH
Every device must authenticate before getting a port. No auth → port stays in unauthenticated VLAN. Stops rogue devices plugging into a jack and getting LAN access.
RADIUS SERVER EAP-TLS
🛡️
L2 — DAI (DYNAMIC ARP INSPECTION)
Switch validates ARP packets against the DHCP snooping binding table. If ARP says "IP X is at MAC Y" but the table says otherwise → drop it. Stops ARP poisoning / MiTM at L2.
ARP POISON KILL DHCP SNOOPING
🚪
L2 — PORT SECURITY
Limit the number of MAC addresses per switch port (e.g. max 2). Exceeding limit → err-disabled. Stops MAC flooding attacks that overflow the CAM table and turn the switch into a hub.
MAX 2 MACs ERR-DISABLE CAM FLOOD KILL
L1 + L2 PRINCIPLE:
Authenticate before you connect.
Physical access + port auth = first two walls.

L3 NETWORK + L4 TRANSPORT
L3 + L4 ROUTING + TRANSPORT
THE INTERNET'S CHOKEPOINTS — CONTROL WHAT ROUTES AND WHAT CONNECTS
🔏
L3 — RPKI + BCP38
RPKI: cryptographically signed ROAs prove which AS owns which prefix. Routers drop INVALID BGP routes → kills BGP hijacking.
BCP38: ISP drops packets whose source IP can't have come from that port → kills IP spoofing + DDoS amplification.
BGP HIJACK KILL IP SPOOF KILL
📋
L3 — ACLs + IPsec
ACLs deny RFC1918 addresses on public interfaces + rate-limit ICMP.
IPsec/ESP encrypts and authenticates every L3 packet in transit — essential for VPN tunnels between sites.
RFC1918 DENY ESP ENCRYPT
🧱
L4 — STATEFUL FIREWALL
Tracks TCP/UDP connection state. Allows ESTABLISHED, RELATED packets back in. Drops unsolicited inbound TCP that never had a SYN. Unlike packet filters — knows context.
STATEFUL CONNTRACK
🍪
L4 — SYN COOKIES + IDS/IPS
SYN cookies: server doesn't allocate state until ACK arrives → SYN flood becomes harmless.
IDS/IPS: signature-based + anomaly detection on flows. IDS alerts, IPS drops inline.
SYN FLOOD KILL SNORT/SURICATA
L3 + L4 PRINCIPLE:
Verify every route. Inspect every connection.
Stateful context makes all the difference.

L5 SESSION · L6 PRESENTATION · L7 APPLICATION
L5 · L6 · L7 SOFTWARE LAYERS
THE INNER WALLS — WHERE MOST VULNS ARE EXPLOITED
🔑
L5 — SECURE SESSION MANAGEMENT
128-bit CSPRNG tokens. Regenerate on login (kills fixation). Short idle timeout (15–30m). Server-side invalidation on logout. HttpOnly + Secure + SameSite=Strict cookie flags.
CSPRNG REGEN ON AUTH
🔐
L6 — TLS 1.3 + HSTS
TLS 1.3 only — deprecate TLS 1.0/1.1/1.2 where possible. 0-RTT handshake, forward secrecy mandatory.
HSTS: tell browsers to always use HTTPS for this domain (max-age 1yr + preload). Kills SSL stripping.
TLS 1.3 HSTS PRELOAD CERT PINNING
🛡️
L7 — WAF + PARAMETERIZED QUERIES
WAF (Web App Firewall) inspects HTTP bodies — blocks SQLi, XSS, SSRF at the edge before hitting your app.
Parameterised queries (prepared statements) eliminate SQL injection at the code level entirely.
SQLi KILL XSS KILL AWS WAF
🔬
L7 — SAST + DAST IN CI/CD
SAST (Static Application Security Testing) scans source code for vulns before build. DAST (Dynamic) hits your running app like an attacker. Both run in the CI/CD pipeline — shift security left.
SHIFT LEFT SEMGREP OWASP ZAP

ZERO TRUST — THE 5 CORE PRINCIPLES
ZERO TRUST PRINCIPLES
NEVER TRUST. ALWAYS VERIFY. ACROSS ALL LAYERS.
1. VERIFY EXPLICITLY
Always authenticate and authorise based on all available data points: identity, location, device health, service/workload, data classification, and anomalies. Not just the network position.
→ 802.1X (L2) · TLS mutual auth (L6) · MFA (L7)
2. LEAST PRIVILEGE ACCESS
Limit user access with just-in-time and just-enough-access. Segment the network so a compromised L2 segment can't reach the database directly — it hits a firewall (L3/L4) first.
→ VLAN segmentation (L2) · ACLs (L3) · RBAC (L7)
3. ASSUME BREACH
Design as if the attacker is already inside. Encrypt all traffic — even internal (IPsec L3, TLS L6). Monitor all lateral movement with IDS (L4). Log everything at all layers.
→ IPsec (L3) · IDS/IPS (L4) · SIEM logging
4. MICRO-SEGMENTATION
Don't give flat network access. Each workload talks only to what it needs — enforced by stateful firewalls and ACLs at L3/L4. East-west traffic (server-to-server) is as controlled as north-south.
→ VLANs (L2) · Firewall rules (L3/L4) · Service mesh
5. CONTINUOUS VALIDATION
Authentication isn't a one-time event. Re-authenticate for sensitive operations. Short session lifetimes (L5). Re-check device health on each connection. SAST/DAST in every CI/CD run (L7).
→ Session timeout (L5) · SAST/DAST (L7) · Cert rotation
ZERO TRUST AT ALL 7 LAYERS:
Verify. Least privilege. Assume breach.
Each principle maps to specific OSI defenses.
