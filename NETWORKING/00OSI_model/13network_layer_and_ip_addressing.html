PACKET JOURNEY — WATCH THE TTL
TTL = 0 → PACKET DROPPED
If TTL reaches 0 before delivery, the router discards the packet and sends an ICMP "Time Exceeded" message back to the source. This is how traceroute works — it sends packets with TTL=1, 2, 3… and reads the "Time Exceeded" replies to map each hop.
traceroute: TTL=1 → maps hop 1 · TTL=2 → hop 2 · …
01
Each router decrements TTL and checks if DST IP is in its routing table. It never reads the payload — just the IP header. Forwards to best next-hop and moves on.
02
Default TTL: Linux=64, Windows=128, Cisco=255. You can fingerprint an OS by the TTL value seen at the destination — a 57 arriving TTL from 7 hops away implies Linux origin.
TTL DESIGN
Prevents infinite loops in misconfigured networks
Before TTL, a routing loop would circulate a packet forever, consuming bandwidth. TTL gives every packet a maximum lifespan — at most 255 router hops.

IPv4 HEADER — FIELD BY FIELD
VERSION & IHL
bits 0–7
Version=4 (IPv4). IHL=header length in 32-bit words. Minimum 5 = 20 bytes. Options can extend it.
TOTAL LENGTH
16 bits
Total size of IP packet (header + data) in bytes. Max 65,535. MTU usually limits to 1500 bytes on Ethernet.
TTL
8 bits
Decremented by 1 at each router. Packet dropped at 0. Linux default=64, Windows=128, network gear=255.
PROTOCOL
8 bits
Identifies what's in the payload so the OS knows which socket to hand it to. Critical for L4 demultiplexing.
6=TCP
17=UDP
1=ICMP
SRC / DST IP
32 bits each
The actual addresses routers use to make forwarding decisions. Never change end-to-end (unlike MAC which changes every hop).

TCP — Transmission Control Protocol
Connection-oriented. Guarantees delivery, order, and error-checking. 3-way handshake before data flows. HTTP, HTTPS, SSH, SMTP all use TCP. Slower but reliable.
17
UDP — User Datagram Protocol
Connectionless. Fire-and-forget. No handshake, no guarantee. DNS, QUIC, VoIP, gaming, streaming use UDP. Fast — but you handle retries yourself.
1
ICMP — Internet Control Message Protocol
Not for data — for network diagnostics. Ping uses ICMP Echo. Traceroute reads ICMP Time Exceeded. TTL=0 sends ICMP back to sender automatically.
KEY TAKEAWAY
IP routes it. Protocol field says what to do with it.
The OS reads the Protocol field and hands the payload to the right L4 handler. No protocol field = no way to demultiplex. It's how one IP can run HTTP, SSH, and DNS simultaneously.
