UDP

Recipient gets envelopes 1, 2, 3 → reassembles the full letter. Transport layer on the receiver does the exact same in reverse.

LAYER 2 — DATA LINK
DATA LINK LAYER LAYER 2
🚚
THE LOCAL DELIVERY TRUCK
IP got the letter to your city. Now the local truck driver knows your exact street. MAC address = physical address on your local network.
📮 POSTAL
Driver has a local street map. Knows every house on the route. Delivers to your specific door.
🌐 NETWORK
Uses MAC address. Knows every device on LAN. Delivers to your NIC specifically.
MAC vs IP ADDRESS
MAC — permanent hardware ID
AA:BB:CC:DD:EE:FF
≠
IP — logical network address
192.168.1.42
KEY PROTOCOLS
Ethernet WiFi 802.11 ARP
ARP = MANIFEST
Asks "who has .42?" Device replies with MAC. Like truck calling: "which house is 42 Elm?"
LAYER 2 — DATA LINK:
MAC address = the local street address.
Delivers between devices on same network.
