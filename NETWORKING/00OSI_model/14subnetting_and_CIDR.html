255 = 8 ones = "this octet is all network" · 0 = 8 zeros = "this octet is all host"
01
Every IP is exactly 32 bits. The /24 prefix means the first 24 bits (3 octets) identify the network. The last 8 bits (1 octet) identify individual devices.
02
The subnet mask 255.255.255.0 is the same information differently expressed. Bits set to 1 = network part. Bits set to 0 = host part. Always contiguous 1s then 0s.
03
A /25 would split the 4th octet: first 4 bits network, last 4 bits host. More prefix = smaller network = fewer hosts. /32 = single host. /0 = entire internet.
THE BINARY TRUTH
Subnet mask in binary: 24 ones then 8 zeros
255 in binary is 11111111. Three of those = /24. The mask ANDed with any IP gives you the network address. That's literally all subnetting is.

01
Why minus 2? The network address (.0) and broadcast address (.255) are reserved — can't assign to hosts. Every subnet loses 2 IPs to these. Always.
02
The block size formula: 256 − subnet mask octet. For /24 (mask=0): 256−0=256 total. For /25 (mask=128): 256−128=128 total. Half the size per extra bit.
KEY FORMULA
Usable hosts = 2^(host bits) − 2
/24 = 2⁸ − 2 = 254. /25 = 2⁷ − 2 = 126. /26 = 2⁶ − 2 = 62. Each extra prefix bit halves the hosts. Memorise these for interviews.

01
Block size = 256 − mask octet. For /25 (mask 128): 256−128=128. Next subnet starts at .128. Then .0 again in the next /24. Subnets always align to multiples of block size.
02
Each additional prefix bit halves the subnet size but doubles the number of subnets. /24 → two /25s. Each /25 → two /26s. This is how you split a network for VLANs.
BLOCK SIZE TRICK
256 − mask = block. Subnets step in block increments.
For /25: 256−128=128. Subnets are .0/.128. For /26: 256−192=64. Subnets are .0/.64/.128/.192. No calculator needed — it's just powers of 2.

REMEMBER
Private IPs never route on the public internet
RFC 1918 ranges (10.x, 172.16–31.x, 192.168.x) are reserved for private use. Your router NATs them to a public IP. That's why every home network can use 192.168.1.x.
