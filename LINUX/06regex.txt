| Symbol | Meaning               |
| ------ | --------------------- |
| .      | Any single character  |  .           :placeholder for one character(use \. escape to match character with dot)
| *      | 0 or more of previous |  *           :0 or more occurences of the previous item
| ^      | Start of line         |  ^ERROR      :regex for lines starting with ERROR
| $      | End of line           |  ;$          :regex for lines ending with semicolon
| []     | Character set         |  [0-9]       :regex for all digits
| [^ ]   | Negated set           |  [^a-zA-Z]   :regex for everything except alphabet(means non-alphabetic character)
| \      | Escape character      |


| Pattern   | Meaning         |
| --------- | --------------- |
| `\{n\}`   | Exactly n times |
| `\{n,\}`  | n or more       |
| `\{n,m\}` | between n and m |


🔹 Extended regex mode (-E) -> Requires extended regex (-E)
Enables:
|   Match one pattern OR another                                            ex:error|failed|timeout
+   One or more times(Match at least one occurrence) of previous item       ex:[0-9]+ matches 1,12,987 etc but not empty ones
?   Zero or one time (optional)                                             ex:https? matches http, https etc(zero or one time 's')
()  Grouping / capturing                                                    Group parts of regex together, Capture matched text for reuse
ex:>sed -E 's/(DB_HOST)=.*/\1=localhost/' .env
(DB_HOST) → capture group
\1 → reuse captured text


🔹 Alternation (OR) — needs -E
sed -E 's/error|failed|timeout/ALERT/g' app.log
Without -E, | must be escaped.


confused notations summary:

| `.`     | Any single character |

| `a+`    | 1 or more `a`        |
| `a?`    | 0 or 1 `a`           |
