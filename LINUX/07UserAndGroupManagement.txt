Sudoers are users who are allowed to run commands as another user (usually root) using sudo.
They do NOT become root permanently — they get temporary, controlled privilege escalation.

🔹 Why sudoers exist (simple reason)

Root has full power (dangerous)

Giving root password to everyone ❌
sudo allows:
Logging
Least privilege
Accountability

>whoami                                                     :name of user we currently logged in as
>who                                                        : list of users who logged into the system 
>w                                                          : people and what they are running
>w -f                                                       :remote hosts(From where user logged in and logintime and the commands which they ran)...useful in incident analysis
>last                                                       :login history(who logged in, from where and when)
>lastlog                                                    :last login per user(ex:lastlog -u username)
>su - <username>                                            :switch user(need target user's password)
>sudo -i                                                    :switch to rootshell
>sudo -l                                                    :show commands that user can run as which user
ex: john ALL=(ALL) ALL
Meaning:
User john
From any host
Can run any command
As any user

ex: jenkins ALL=(ALL) NOPASSWD:/usr/bin/systemctl restart nginx
👉 Jenkins can only restart nginx
👉 No password required
👉 No root shell access

>id                                                         :ids of current user
>id <username>                                              :userid, groupid groups etc
>sudo ps -u <username>                                      :show processes used by a user
>sudo -i                                                    :root shell
>sudo -u user                                               :run as another user
>sudo -k                                                    :clear cached credentials
>sudo -v                                                    :extend timeout

Commands vary slightly by distro
Debian/Ubuntu → useradd, adduser
RHEL/CentOS → useradd

User and group management:
>sudo useradd <username>                                    :create a user, User is added to a private group with same name: john → john
>sudo useradd -m <username>                                 :give user their home directory(/home/<user>) at the time of creation and assign ownership to owner
>sudo useradd -m -g <group> <username>                      :create user+ assign primary group+ create home directory
>sudo useradd -m -G <group1>,<group2>,... <username>        :create user with secondary groups
ex: sudo useradd -m -g developers -G docker,jenkins username
creating user with primary and secondary groups
>sudo useradd -m -d /opt/<appuser> <username>               :user with custom home directory
>sudo useradd -r -s /sbin/nologin <appuser>                 :create system/service user(No login)...used for nginx, jenkins, docker services when services dont need a shell(prevents attackers from logging)
>sudo useradd -u <uid> -g <gid> <username>                  :creating user with specific uid and gid
ex: sudo useradd -u 1050 -g 1050 john                       :creating user with specific uid and gid

>passwd                                                     :set password of user we currently logged in as
>sudo passwd <username>                                     :set/update password(never set password while creating user using -p flag. -p expects an already HASHED password. set password using this seperate command only)
Using plain text is insecure and may leak via shell history or ps
>sudo useradd -m <username> && sudo passwd <username>       :password during creation
>sudo useradd -m -s /bin/bash username                      :create user with home + shell(-s)
>getent passwd <username>                                   :get single user info(cat /etc/passwd for info of all users)
>cat /etc/group                                             :list all groups
>sudo cat /etc/shadow                                       :list of hashed passwords of all users along with expiry and aging info
>sudo usermod -L <username>                                 :Lock user(disable login) usecase: if 3 unsuccessful attempts
>sudo usermod -U <username>                                 :unlock user login(enable login)
>groups <username>                                          :check groups of a user
>sudo usermod -aG <group> <username>                        :add user to a particular group(-a :append(don't forget, without this user will be removed from other groups), -G secondary group)
>sudo usermod -g <group> <username>                         :change primary group
>sudo usermod -aG sudo <username>                           :making a user sudoer
>sudo userdel <username>                                    :removes user but his home directory remains
>sudo userdel -r <username>                                 :remove user and his home directory


Verify user setup:
>id <username>
>groups <username>
>getent passwd <username>


>getent group <groupname>                                   :groupid, inspect members, get entries
>sudo groupadd <groupname>                                  :create a group
>sudo groupadd <groupname> -U <user1>,<user2>...            :add users to a group at the time of group creation
>cat /etc/group                                             :list all groups
>getent group <groupname>                                   :see users in a particular group
>sudo groupmod -n <newgroup> <old/presentgroup>             :rename a group
>sudo groupmod -aU <user1>,<user2>,...  <groupname>         :add users to a group(append userslist)...existing members remain
>sudo groupdel <groupname>                                  :delete a group
>ls -l                                                      :check ownership and permissions
>sudo chgrp <groupname> <directory>                         :change group of a directory
>sudo chgrp -R <groupname> <directory>                      :recursive group change
>chmod g+s <directory>                                      :group inheritance
