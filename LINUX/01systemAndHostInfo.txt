System information (kernel-level)
>uname                      : kernel name
>uname -r                   : kernel version
>uname -n                   : hostname of machine
>uname -m                   : machine hardware
>uname -o                   : machine os
>uname -p                   : processor type
>uname -a                   : every possible info about the system
>man uname



Host Machine and identity: Shows complete host information Hostname, OS, Kernel, Architecture, Virtualization
>hostname -I                :ip address of machine
>hostname -f                :fully qualified domain name
>sudo hostnamectl set-hostname <name>

>hostnamectl                :every possible info about host
>man hostname



Distribution specific info:
>lsb_release -i                 :distribution id ex:Ubuntu, Debian
>lsb_release -r                 :release version
>lsb_release -a                 :every possible info
>sudo apt install lsb-release   :if lsb_release is missing

>arch                           :architecture info
>cat /proc/version              :system info

>lsmod                          :list of all modules present
>modinfo <module>               :module specific info
>man modinfo



Package management:
Debian/Ubuntu(Advanced package tool)
>sudo apt upgrade                                            :upgrades all installed packages to latest available versions
>sudo apt update                                             :Check latest version from repos(refreshes local package index)
>sudo apt install/remove/show/search <packagename>           :install/remove a package

RHEL/CentOs/Fedora(YUM)
>sudo yum update                                             :update system packages
>sudo yum install/remove <packagename>
Fedora/RHEL 8+(DNF)...modern replacement for yum
>sudo dnf update

OpenSUSE(Zypper)
>sudo zypper refresh               :refresh repositories
>sudo zypper install <packagename>

Working directly with package files(low-level)
Debian packages(dpkg)
>sudo dpkg -i <package-file>.deb        :install .deb file
>sudo dpkg -r <pkgname>                 :remove package
>sudo dpkg -s <pkgname>                 :show package status
>dpkg -L <pkgname>                      :List all files installed by the package
>dpkg -l                                :list all installed packages
NOTE:dpkg does not resolve dependencies automatically

RHEL packages(RPM)
>sudo rpm -ivh pkg.rpm              :install rpm package
>sudo rpm -e <pkgname>              :remove a rpm package
>rpm -qa                            :list all installed RPM packages
>rpm -qi <pkgname>                  :show information about installed package
>rpm -ql <pkgname>                  :list files installed by package

Universal package manager(SNAP)
>sudo snap install/remove <packagename>           
>snap list                                  :list installed snap packages
>snap info <pkgname>                        :detailed info about snap
>sudo snap refresh                          :update installed snap packages
NOTE: snap works across almost all linux distros
