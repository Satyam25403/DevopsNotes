File Creation and Viewing
>echo "sample text"
>echo "file content" > <filename> :overwriting contents of file
>echo "file content" >> <filename> :appending contents to existing file

>cat <filename>                       :display file contents
>cat <file1> <file2>...               :contents of multiple files together
>cat <file1> <file2> > <combinedfile> :merge files
>less <filename>                      :displays interactive view which we can scroll through(line by line)
>more <filename>                      :same as less by displays(only page by page)
>head -n <number> <file>              :display first n lines
>tail -n <number> <file>              :display last n lines



File creation editing and access
>touch <filename with extension> : create a file

>vi/nano <filename>     :edit a file with editor

>chmod <permission> <filename>  :change file permissions(read=4, write=2, execute=1)

>cp <src_file> <targetfile/directory>   : copy to a destination or to some file(duplicate contents)
>cp -r <src_folder> <destination_folder> :copy whole directory recursively(use -p to preservee permissions and timestamps)
>mv <src_file> <targetfile/directory>   : move to a destination or to some file(rename)



Directory Operations
>mkdir <directory>
>mkfir -p </nested/directory/path> :create a nested directory
>rmdir <directory>      :remove empty directory only
>rm -rf <directory> :for recursive and force removal
>rm -r -i <directory> :prompt before deletion(interactive deletion)



Navigation and listing
>cd <path>      :navigate to a directory
>pwd            :print working directory
>ls             :list contents of current directory
-l :file permissions, -a :include hidden files, -R :resursively
>ls -lar        :common combination(permissions+hidden+recursive listing)



Command chaining and background execution
<command1> && <command2>        :run both
<command1> || <command2>        :run second only if first fails
<command> &                     :run in background
>nohup <command> &              :run even after logout(server-safe)



IO and Redirection errors
2> /dev/null :(discard error output), > :(overwrite output), >> :(append output)
<command> 2> /dev/null                      :forward error logs to that directory(ignore all output)
<command> > output.log 2> error.log         :forward output to output.log and error to error.log(seperate output and error logs)
<command> > output.log 2> &1                :forward output as well as error to same place(output.log)
<command> >> output.log 2>&1                :append instead of overwrite
<command> 1>/dev/null 2>error.log           :log only errors



Comparision Operators
-lt, -gt, -le, -ge, -eq, -ne :(for numbers)(less than, greater than, less or equal, greater or equal, equal to, not equal)
==, !=  :(for strings)



Searching Files and directories
>find <directory> -name <filename> (or) >locate <filename> :search for a file in a particular directory
search options: -name <filename>, -type f : for files, -type d :for directory , -perm=<permission ex:777>, -mtime -n :(modified in past n days)
>locate -i "*.log"  :locate log files(alternative of find)
