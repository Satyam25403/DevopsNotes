A shell script is a file containing Linux commands executed sequentially by a shell (usually bash). we can also pass
command line args to scripts just like we pass in ex:c language programs

Steps:
0:check available shells to use in shebang line         >which bash (or) echo $SHELL
1.Make <filename>.sh or directly open editor            >vi/nano <file>.sh
2.write script
3.make it executable                                    >chmod +x hello.sh
4.run(with optional args)                               >./<file>.sh <arg1> <arg2>...
ex: ./hello.sh 
===============================================================================
Hello world script:

#!/bin/bash                         :shebang (tells system which shell to use)...run >which bash or >echo $SHELL to find 
echo "Hello, World!"

================================================================================
script with variables:

name="Sagar"                            :Define a variable(No space around '=')
echo "Hello $name"                      :usage of variable

read -p "Enter your name: " name        :take input from user(by displaying prompt in'""')
echo "Welcome $name"

You can use the values that linux commands return, in ur script: Command substitution
echo "Uptime: $(uptime)"                :uptime is a linux command

================================================================================
Args in script:

#!/bin/bash
echo "First arg: $1"
echo "Second arg: $2"
echo "All args: $@"
echo "Total args: $#"

make it executable and run using:
>./script.sh dev prod

Comparision operators:
Numbers:
-eq  -ne  -lt  -le  -gt  -ge

Strings:
==  !=  -z (empty)  -n (not empty)

Logical operators:
cmd1 && cmd2            # run cmd2 only if cmd1 succeeds
cmd1 || cmd2            # run cmd2 if cmd1 fails

File and directory check operators:(-f, -d, -r, -w, -x, -s)
if [ -f file.txt ]; then
  echo "File exists and is a regular file"
fi
if [ -r file.txt ]; then
  echo "File is Readable"
fi
if [ -w file.txt ]; then
  echo "File is Writable"
fi
if [ -x script.sh ]; then
  echo "Executable"
fi
if [ -s file.txt ]; then
  echo "File is not empty"
fi

if [ -d /etc ]; then
  echo "Directory exists"
fi


===============================================================================

Conditionals:
if [ "$user" == "root" ]; then
  echo "Admin user"
fi

if [ $age -ge 18 ]; then
  echo "Adult"
else
  echo "Minor"
fi

case $1 in
  start)
    echo "Starting service"
    ;;
  stop)
    echo "Stopping service"
    ;;
  restart)
    echo "Restarting service"
    ;;
  *)
    echo "Usage: $0 {start|stop|restart}"
esac

===============================================================================
Loops:
For loop:
for i in 1 2 3 4 5
do
  echo $i
done

While loop:
count=1
while [ $count -le 5 ]
do
  echo $count
  ((count++))
done

===============================================================================
Functions, output redirection and exit status:

backup() {
  echo "Backup started"
}
backup                          :calling function

command > output.txt            :overwrite
command >> output.txt           :append
command 2> error.txt
command > all.txt 2>&1


echo $?                         :print exit status(0: success, non-zero: failure)

Usage:
if [ $? -ne 0 ]; then
  echo "Command failed"
fi
