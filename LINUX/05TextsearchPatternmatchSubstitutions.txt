awk: awk is a pattern scanning and text processing tool
awk is a powerful text processing language used for column-based filtering, aggregation, and reporting in Linux
It works line by line, splitting each line into fields (columns).

Basic syntax:
awk 'pattern/condition { action }' filename
If no pattern → action applies to all lines.
If pattern specified, action applies to only the lines having matched patterns

Fields and Built-in variables
$0 → entire line(remember it works line by line seperating at field-seperator F)
$1 → first column
$2 → second column
$NF → last column
NF → number of fields
NR → line number
Default field separator = space

Change field seperator:
>awk -F<new-seperator> '{action}' <file/directory>  
ex: awk -F, '{print $1, $3}' data.csv

🔹 Built-in functions
length($0)
toupper($1)
tolower($1)
substr($1,1,4)

Awk programs can have 3 blocks:
BEGIN  → before reading file
MAIN   → for each line
END    → after file ends

BEGIN block:
>BEGIN {print "START"}

Runs once, Before reading any line
Used for headers, initialization

MAIN block:
>{print $1}
Runs for every line

END block:
>END {print "END"}
Runs once, After all lines are processed
Used for summaries, totals

Output example
START
col1_line1
col1_line2
...
END

Full command:
>awk 'BEGIN {print "START"} {print $1} END {print "END"}' file.txt

some examples:
>awk '{sum += $2} END {print sum}' data.txt
>awk '{sum += $2; count++} END {print sum/count}' data.txt
Meaning
for each line {sum += $2} → add column 2 value to variable sum, increment linecount
END {print sum/count} → print final avg

📌 sum starts as 0 automatically

🔹 Why awk is powerful (DevOps view 🔥)
No temp files
Single-pass processing
Handles huge logs efficiently

Used in:
Monitoring
CI/CD pipelines
Log analysis
Reporting

🔹 What is sed(Stream EDitor)?
sed edits text streams:
Files
Command output
Piped input

📌 By default:
It does NOT modify the file
It just prints modified output to stdout

Basic syntax
>sed '<command>' <filename>

>sed 's/old/new/' file.txt                      :replace first occurence per line(Substitute: s)
>sed 's/old/new/g' file.txt                     :replace all occurences(g flag) per line
>sed 's/error/ERROR/gi' file.txt                :case insensitive replace
-i :edits the file directly
>sed '5s/old/new/' file.txt                     :replace on specific line
>sed '3,10s/foo/bar/g' file.txt                 :replace in line range
>sed -i 's/old/new/g' file.txt                  :inplace edit(changing port in a config file: sed -i 's/8080/9090/g' app.conf)...modifies directly
>sed -i.bak 's/old/new/g' file.txt              :inplace edit with backup...safer on production
>sed -n '5p' file.txt                           :print specific line
>sed -n '5,10p' file.txt                        :print range of lines
>sed '5d' file.txt                              :delete specific line
>sed '5,10d' file.txt                           :delete a range of lines
>sed '/ERROR/d' app.log                         :pattern based delete(removes lines containing ERROR)
>sed '5i This is new line' file.txt             :insert before line 5
>sed '5a This is new line' file.txt             :append after line 5
>sed 's/[0-9]\+/NUMBER/g' file.txt              :replacing using regex(replacing env vars in CI/CD: sed -i "s/DB_HOST=.*/DB_HOST=$DB_HOST/" .env)
>sed -e 's/foo/bar/g' -e 's/old/new/g' file.txt :multiple sed commands
