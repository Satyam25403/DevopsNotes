Filesystem usage(Disk Free)df
>df                     :hows filesystem, used, available, and mount point
>df -T                  :(type of fs and info)
>df -a                  :(all accessible info including pseudo/virtual ones)
>df -h </path>          :disk usage of specific mount point
>df -i                  : show inode usage(disk can even be full even when space is free:inodes exhaustion)
if disk is full but 
>df -h , looks fine then check >df -i



DiskUsed
>du -h                  :diskusage in human readable format
>du -sh <path>          : Total size of directory or path
>du --time              :last modification time along with size
>du -a                  :everything we can accessible(disk usage of files+ directories)
>du -xh                 :stay on same filesystem only(important while handling servers)



Memory(RAM)
>free -h                :how much RAM used, remaining, shared etc.



Block Devices and partitions
>lsblk                              :list block devices; show disks, partitions, mount points(in tree format)
example:
sda     447G
├─sda1  100M  /boot
├─sda2  16G   [SWAP]
├─sda3  430G  /
└─sda4  500M
📌 sda → disk
📌 sda1, sda2 → partitions
>lsblk -f                           :Filesystem type + UUID + mount point
>sudo fdisk -l                      :list all disks and partitions(disk size, partition type, start/end sectors)
>sudo fdisk /dev/sdb                :open disk for partitioning(in interactive mode)
common fdisk commands
p → print partitions
n → new partition
d → delete partition
w → write changes
q → quit without saving
changes apply only after 'w'
>sudo parted                        :a modern partition tool(opens an interctive shell)
inside parted, >print               :shows partitions
>sudo parted /dev/sdb               :open a specific disk
commands inside:
print
mkpart
rm
quit
parted supports large disks (>2TB) better than fdisk.
>mount                              :currently mounted filesystems
>findmnt                            : cleaner mount hierarchy view

Workflow to create a new partition:
1.>lsblk                                                  :check disks...identify the disk and free space(Always first)
2.>sudo fdisk /dev/sdb (or) >sudo parted /dev/sdb         :open fdisk on target disk(interactive)
3.inside fdisk
print existing partitions   : p
✔ Shows current partition table
✔ Confirms free space availability
create new partition        : n  
You’ll be asked:
Partition type (primary/logical)
Partition number
Starting sector (press Enter → default)
Ending sector or size (+10G, +500M) 📌 Example: +10G

4.Accept default sector values
If enough space exists:
Press Enter for start sector
Press Enter or specify size
fdisk auto-aligns sectors.

5️.Write changes & exit fdisk
w
✔ Writes partition table
✔ Exits fdisk
⚠️ Changes apply ONLY after w

6.>sudo mkfs.ext4 /dev/sdb5                               :create filesystem(ext4 or xfs or ext3)
7.>sudo mkdir /mnt/newdisk                                :create mount directory
8.>sudo mount /dev/sdb5 /mnt/newdisk                      :mount the partition...partition is now usable
>df -h && lsblk                                           :verify...mount point and size



Make mount permanent(/etc/fstab):
>blkid
copy uuid and then
>sudo vi /etc/fstab
add this entry:     UUID=xxxx /data ext4 defaults 0 2
>sudo mount -a                                            :test



Cleanup/Unmounting/Delete partition:
>sudo umount /mnt/newdisk                                 :unmount filesystem(must unmount before deletion)
>sudo fdisk /dev/sdb5                                     :delete partition using fdisk
in fdisk: 
enter >d 
then select partition number and then
>w
partition will be removed



Filesystem check(fsck):
>sudo fsck /dev/sdb5                                      :check filesystem integrity(check for corruption and inconsistencies)
>sudo fsck -y /dev/sdb5                                   :auto-fix detected issues
Run fsck only on unmounted filesystems
Before making changes to partitions, always back up data
🔥 This is CRITICAL in production.

Swap partition: Logical backup of RAM
Swap is a disk space used when RAM is exhausted
Helps preventing OOM(Out of memory) Kills

Swap partition creation:
1.>lsblk -f                 :identify disks(Disk /dev/sda, free/unallocated space)
2.>sudo fdisk /dev/sda      :open fdisk
a.Create a new partition inside fdisk:
n
Choose: p → primary (recommended)
Partition number (e.g. 5)
b.Specify partition size
Example: +2G
c.Change partition type to swap
t
Enter: 82
✔ 82 = Linux swap
d.Write changes
w

✔Partition will be created

3.>sudo mkswap /dev/sda5            :format swap partition(marks partition as swap space)
4.>sudo swapon /dev/sda5            :enable swap...swap becomes active
5.>swapon --show    (or) >free -h   :verify swap

Make swap permanent:
>sudo nano /etc/fstab               :edit fstab
add this: /dev/sda5 none swap sw 0 0
📌 Meaning:
/dev/sda5 → swap partition
none → no mount point
swap → filesystem type
sw → enable swap
0 0 → no dump/fsck

Test fstab entry
>sudo swapoff -a
>sudo swapon -a
If no error → fstab is correct.

turning off swap:
>sudo swapoff /dev/sda5
used when: resizing swap/deleting swap


Swap file(instead of partition(preferred in cloud)):
>sudo fallocate -l 2G /swapfile
>sudo chmod 600 /swapfile
>sudo mkswap /swapfile
>sudo swapon /swapfile
fstab entry:
/swapfile none swap sw 0 0
📌 Easier to resize than partitions.


Monitoring swap usage:
>vmstat
>htop
