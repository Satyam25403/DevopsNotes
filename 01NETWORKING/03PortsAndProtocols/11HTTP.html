SECURITY HEADERS
WHAT EACH ONE BLOCKS
ADD THESE 4 HEADERS
X-Frame-Options
CLICKJACKING
X-Frame-Options: DENY
Prevents your page being embedded in an iframe on attacker's site. DENY = never frame. SAMEORIGIN = your domain only.
X-Content-Type-Options
MIME SNIFF
X-Content-Type-Options: nosniff
Browser won't override Content-Type. Without this, a browser may execute a .jpg as JS if the content looks like a script.
Strict-Transport-Security
SSL STRIP
Strict-Transport-Security: max-age=31536000; includeSubDomains
Forces HTTPS for 1 year. Browser won't downgrade to HTTP. Blocks SSLstrip MITM attacks on public WiFi.
Content-Security-Policy
XSS
Content-Security-Policy: default-src 'self'; script-src 'self'
Whitelist which origins can load scripts, styles, images. Most powerful XSS mitigation at the browser level.
Four headers, four different attack classes blocked.
Add them in nginx.conf or Apache .htaccess — 5 mins.
