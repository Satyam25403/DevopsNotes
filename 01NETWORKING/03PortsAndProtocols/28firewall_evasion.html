⚠ MODERN FIREWALLS
Next-gen / stateful firewalls reassemble fragments before inspection — fragmentation doesn't help. Effective only against old stateless packet filters and some IDS sensors.

SLOW SCAN EVASION
HOW IDS DETECTS PORT SCANS
Most IDS use a connection-rate threshold: if one IP sends SYNs to >N ports within T seconds, fire an alert. Default Snort rule: 15 ports in 0.5 seconds.
SCAN RATE vs IDS THRESHOLD
timing options
nmap -T0 TARGET   # paranoid — 5min between probes
nmap --scan-delay 5s TARGET  # 5sec between ports
nmap --max-rate 1 TARGET   # 1 packet per second
# -T0 scan of 1000 ports ≈ 3 days
⚡ REAL-WORLD TRADE-OFF
In red team engagements: use --scan-delay 2s — slow enough to avoid most IDS thresholds, fast enough to complete in hours. -T0 is for ultra-paranoid, multi-day ops.
IDS detects scans by connection rate — send slow enough and you're invisible.
--scan-delay 2s is the red team sweet spot: stealthy but still finishes today.

HOW IPID LEAKS PORT STATE
Idle hosts increment IPID on every packet sent. If target's SYN-ACK causes zombie to RST (IPID+2), port is open. If RST goes back (IPID+1), port is closed.
