HOW NLA WORKS (CredSSP):
NLA uses CredSSP (Credential Security Support Provider) — TLS tunnel + Kerberos/NTLM auth happens before RDP session is allocated
Server never reaches the vulnerable RDP code path until valid credentials are supplied — BlueKeep can't reach the MS_T120 channel
Also protects against credential theft: password is never transmitted in cleartext — CredSSP uses delegation tokens
