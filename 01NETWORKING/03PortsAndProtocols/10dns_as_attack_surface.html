🔐 FIX AXFR — ZONE TRANSFER
# BIND9 named.conf
allow-transfer { secondary-ns-ip; };
also-notify { secondary-ns-ip; };
Restrict AXFR to secondary NS IPs only. Default should be deny all. Verify with: dnsrecon -d yourdomain -t axfr
🚧 FIX TUNNELING
• Block outbound :53 to all resolvers except your internal DNS
• Inspect DNS for long subdomain labels (>50 chars)
• Alert on >100 TXT queries/min from single host
🛡️ FIX LLMNR — GPO
GPO: Computer Config → Admin Templates
→ Network → DNS Client
→ Turn off multicast name resolution = ENABLED
Also disable NBT-NS in network adapter settings. Without LLMNR, Responder has no broadcast to poison.
