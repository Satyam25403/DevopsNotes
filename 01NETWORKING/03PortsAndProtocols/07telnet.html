HOW TO KILL TELNET EVERYWHERE
THE FIX REMEDIATION
1
DISABLE TELNETD
# Linux (systemd)
systemctl stop telnet.socket
systemctl disable telnet.socket
# Cisco IOS
line vty 0 4
transport input ssh
2
BLOCK PORT 23 AT FIREWALL
# iptables
iptables -A INPUT -p tcp --dport 23 -j DROP
iptables -A OUTPUT -p tcp --dport 23 -j DROP
# Also block outbound — prevent exfil
3
REPLACE WITH SSH
Install: openssh-server
Enable key auth, disable password auth
Use port 22 (or non-standard for obscurity)
For old gear that only supports telnet: replace hardware or put it in an isolated VLAN with no internet path
VERIFY IT'S GONE:
$ nmap -p 23 target
