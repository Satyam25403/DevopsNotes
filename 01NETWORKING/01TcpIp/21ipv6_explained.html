ABBREVIATION RULES — STEP BY STEP:
FULL ADDRESS:
2001:0db8:0000:0000:
0000:0000:0000:0001
RULE 1 — drop leading zeros in each group:
2001:db8:0:0:0:0:0:1
0db8 → db8  |  0000 → 0
RULE 2 — replace longest run of :0: with :: (once only):
2001:db8::1
:0:0:0:0:0:0: → ::  (6 groups collapsed)
✓ FINAL COMPRESSED FORM:
2001:db8::1
39 chars → 11 chars. Same address.
:: can appear ONCE per address.
Expand by filling zeros until 8 groups.
:: = one or more groups of 0000
128 bits = 8 hex groups, colon-separated

ADDRESS TYPES & SCOPES
FOUR ADDRESS TYPES SCOPE
Every IPv6 address has a scope.
The prefix tells you exactly what it is.
GLOBAL (internet)
SITE / UNIQUE LOCAL
LINK-LOCAL
(same subnet)
2000::/3
Global Unicast Address (GUA)
Routable on the internet. Like IPv4 public IP.
Assigned by ISP. Starts with 2 or 3.
Example: 2001:db8::1
fe80::/10
Link-Local Address (LLA)
Auto-configured on every interface. Never routed.
Used for NDP, router discovery on the segment.
Example: fe80::1%eth0
fc00::/7
Unique Local Address (ULA)
Private IPv6 — like RFC1918 (10.x, 192.168.x).
Routable within org, not on internet.
Example: fd12:3456:789a::1
ff00::/8
Multicast (replaces broadcast!)
Sent to a group, not a single host.
ff02::1 = all nodes  |  ff02::2 = all routers
No broadcast in IPv6 — ever.
QUICK PREFIX LOOKUP:
2xxx / 3xxx→ Global fe80::→ Link-local fc:: / fd::→ Private ff::→ Multicast
Prefix = scope. fe80 = link only. ff = group.

IPv6 ARCHITECTURE
NDP REPLACES ARP
NEIGHBOR DISCOVERY ICMPv6
IPv4 ARP = layer-2 broadcast storm.
NDP = ICMPv6 multicast, targeted & efficient.
ARP (IPv4)
• Layer 2 broadcast
• "Who has 10.0.0.1?"
• ALL hosts wake up
• No auth → spoofable
• O(n) on large LANs
NDP (IPv6)
• ICMPv6 multicast
• "NS to ff02::1:ff…"
• Only target wakes
• SEcure NDP (SEND)
• Scales to huge nets

NDP ICMPv6 TYPES:
Type 133 Router Solicitation  (RS) — "any routers?"

SECURITY NOTE: NDP is spoofable too.

SEND (RFC 3971) uses crypto — rarely deployed.
NDP = ICMPv6 types 133–137. ARP is gone.

SLAAC — SELF-CONFIGURE WITHOUT DHCP
SLAAC STATELESS
SLAAC = Stateless Address Auto-Configuration
No DHCP server needed. Router provides prefix.
Host generates its own Interface ID.
