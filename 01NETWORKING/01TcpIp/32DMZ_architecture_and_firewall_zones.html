DMZ ARCHITECTURE
IPTABLES + ZONE-BASED FIREWALL
IPTABLES CONFIG PRODUCTION
Default DROP policy. Allow only what you explicitly permit.
INNER FIREWALL — iptables
# Default DROP everything
iptables -P FORWARD DROP
iptables -P INPUT DROP
# Allow established sessions (stateful)
iptables -A FORWARD -m state
  --state ESTABLISHED,RELATED -j ACCEPT
# Inside → DMZ: allow SSH for admin
iptables -A FORWARD -i eth1 -o eth0
  -p tcp --dport 22 -j ACCEPT
# DMZ → Inside: DENY ALL (the rule)
iptables -A FORWARD -i eth0 -o eth1
  -j DROP

INTERVIEW ANSWER
"Use zone-based firewall policy. Zones abstract the physical topology — you define trust levels once, rules apply automatically as interfaces join zones. More maintainable at scale."
Default DROP. Stateful ESTABLISHED,RELATED tracking. Explicit ACCEPT only.
Zone-based policy scales. Interface ACLs break under topology changes.
