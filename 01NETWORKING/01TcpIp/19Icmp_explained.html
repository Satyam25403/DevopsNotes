ICMP — MORE THAN PING
WHAT YOU CAN AND CAN'T BLOCK
FIREWALL RULES SUMMARY
"Block all ICMP" is a dangerous myth.
These types MUST be allowed:
✅
TYPE 3 CODE 4 — Frag Needed
Required for PMTUD — blocks silently break TCP
✅
TYPE 11 — Time Exceeded
Required for traceroute / path diagnostics
✅
TYPE 8/0 — Echo Req/Reply
Allow outbound; inbound optional
⚠️
TYPE 5 — Redirect
Block or disable on hosts — attack vector
🚫
TYPE 17/18 — Address Mask
Obsolete — block safely
IPv6 MAKES IT WORSE
ICMPv6 Types 133–137 are NDP
(Neighbor Discovery Protocol)
Blocking ICMPv6 = IPv6 totally breaks
No ARP, no router discovery, nothing.
ICMP = network's error layer.
Filter selectively, never blindly block.
The security rule: filter ICMP, never nuke it
