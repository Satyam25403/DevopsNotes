SERVER SIDE: SYN_RCVD
Between rcv SYN and rcv final ACK, server holds socket in SYN_RCVD. Stored in SYN backlog queue.
Too many SYN_RCVD = SYN flood (see scene 3).

⏱ TIME_WAIT — NOT A BUG
⏲
2×MSL countdown (≈60s)
0s30s60s ✓
After 4-way close, initiating side holds state 2×MSL.
MSL = Maximum Segment Lifetime ≈ 30s → 2×MSL = 60s.
Absorbs delayed/duplicate packets from old connection.
10,000 TIME_WAIT entries = normal for busy server.
