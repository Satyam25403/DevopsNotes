DETECTION — NDPmon & MONITORING
DETECTION TOOLS
Detecting IPv6 attacks requires
IPv6-aware tooling.
Most SIEMs log zero IPv6 out of the box.
NDPmon — PASSIVE MONITOR
Listens for all NDP traffic. Builds
legitimate address tables. Alerts on:
• New Router Advertisement sources
• MAC-to-IPv6 mapping changes (poison)
• Prefix changes mid-session
[NDPmon ALERT 14:32:01]
ROGUE RA DETECTED
src: fe80::dead:beef (new router!)
prefix: 2001:db8::/64 pref=HIGH
→ RA Guard should block this
CAPTURE IPv6 TRAFFIC:
# Capture all ICMPv6 on segment
tcpdump -i eth0 icmp6

# Filter RA packets only
tcpdump -i eth0 'icmp6[0]==134'

# Detect rogue RAs (scapy)
ip6tables -A INPUT -p icmpv6 \
 --icmpv6-type 134 -j LOG \
 --log-prefix "RA-ALERT: "
