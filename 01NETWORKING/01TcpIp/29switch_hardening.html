① PORT SECURITY
PORT SECURITY MAC LIMIT
ATTACK: MAC FLOOD
Attacker sends frames with thousands
of fake source MACs → fills CAM table
→ switch floods all traffic like a hub.
CONFIG — PORT SECURITY
interface GigabitEthernet0/1
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation shutdown
 switchport port-security mac-address sticky
maximum 2
Only 2 MACs per port. 3rd MAC triggers violation.
shutdown
Port goes err-disabled. Admin must re-enable.
sticky
First MACs seen are auto-learned and saved to config.
VERIFY
show port-security interface Gi0/1
show port-security address
Sticky + shutdown = zero-config MAC whitelist.
MAC flood fills 2 slots then port shuts. Attack over.

② BPDU GUARD
blocks STP attack
BPDU on access port = attacker running STP.
Shut the port immediately.
interface GigabitEthernet0/1

 spanning-tree bpduguard enable
! or globally:
spanning-tree portfast bpduguard default
③ DHCP SNOOPING
blocks rogue DHCP
Rogue DHCP server gives attacker-controlled
gateway IP. Only trusted uplink responds.

⑤ STORM CONTROL
blocks broadcast storms
Rate-limits broadcast / multicast / unicast
to % of port bandwidth. Exceeding →
packets dropped or port shut.
interface GigabitEthernet0/1
 storm-control broadcast level 20.00
 storm-control multicast level 20.00
 storm-control action shutdown
DAI needs DHCP snooping as its
truth source. Enable snooping first.
DAI: every ARP checked against binding table.
Storm control: 20% broadcast ceiling, then shut.
