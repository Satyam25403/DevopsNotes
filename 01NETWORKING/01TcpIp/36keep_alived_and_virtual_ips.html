GRATUITOUS ARP — WHY IT MATTERS
Normally ARP is a question: "who has 10.0.0.100?"
Gratuitous ARP is an unsolicited announcement.
Every device on the LAN updates its ARP cache.
New packets go to Server B's MAC instantly.
Keepalived detects failure via missed VRRP advertisements (dead_interval).
Gratuitous ARP flushes every switch and client ARP table. Sub-second takeover.

CONFIG + VIP vs DNS FAILOVER
KEEPALIVED CONFIG PRODUCTION
Minimal keepalived.conf — master side:
vrrp_instance VI_1 {
  state MASTER
  interface eth0
  virtual_router_id 51
  priority 110
}
  virtual_ipaddress {
    10.0.0.100/24 dev eth0
  }
  track_script { chk_nginx }
vrrp_script chk_nginx {
  script "/usr/bin/pgrep nginx"
  interval 2  # check every 2s
  weight -20  # drop priority if fails
}

INTERVIEW ANSWER
"Keepalived VIP gives sub-second, transparent failover within a LAN. DNS failover is TTL-bound and forces client reconnection. Use VIP for database HA, DNS for cross-region DR."
track_script drops priority when nginx dies — backup wins election automatically.
