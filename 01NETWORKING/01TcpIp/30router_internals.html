ROUTER HARDENING
SOURCE ROUTING · uRPF · CoPP
SECURITY HARDENING
DISABLE SOURCE ROUTING
IP OPTION
IP source routing lets the sender dictate the path through routers — bypass firewalls, map topology, spoof return paths.
# Cisco IOS
no ip source-route
# Linux sysctl
sysctl -w net.ipv4.conf.all.accept_source_route=0
uRPF — ANTI-SPOOF
URPF
Unicast Reverse Path Forwarding: check that the source IP of an incoming packet is reachable via the same interface it arrived on. Drops spoofed packets.
# Cisco — enable on ingress interface
ip verify unicast source reachable-via rx
CONTROL-PLANE POLICING
CoPP
Rate-limits traffic destined for the router's CPU (control plane). Prevents CPU exhaustion attacks — e.g. flooding with TTL=1 packets to overwhelm process switching.
# Cisco MQC policy-map applied to control-plane
service-policy input COPP-POLICY
Three controls every router needs in prod.
Source-route off. uRPF on ingress. CoPP always.
