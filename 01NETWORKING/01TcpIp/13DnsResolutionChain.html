TTL — TIME TO LIVE
TTL=300: answer cached for 5 minutes. Second visit: <1ms from resolver cache.
Low TTL (60s): fast failover when IP changes. High DNS query load.
High TTL (86400s): cached for 24h. IP changes take 24h to propagate.
DNS TTL ≠ HTTP cache. Two separate caching systems.
