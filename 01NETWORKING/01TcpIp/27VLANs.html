Tag Protocol ID — marks frame as 802.1Q

0–4094 · This IS the VLAN number
12 bits = 4096 possible VLANs (0 & 4095 reserved).

802.1Q inserts 4 bytes after source MAC.
12-bit VLAN ID = up to 4094 logical networks.

NATIVE VLAN RISK
NATIVE VLAN = UNTAGGED ON TRUNK

without an 802.1Q tag.
Default on Cisco: VLAN 1.

⚡ VLAN HOPPING ATTACK
Attacker on VLAN 1 sends
double-tagged frames: outer tag = 1
(stripped at first trunk), inner tag
reaches VLAN 10 — the medical network.
✓ FIX: CHANGE NATIVE VLAN
switchport trunk native vlan 999
# use unused VLAN, never VLAN 1
Native VLAN travels untagged on trunks.
Never leave it as VLAN 1 — change it to an unused ID.
