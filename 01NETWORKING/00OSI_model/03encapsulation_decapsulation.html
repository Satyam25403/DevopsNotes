L7 DATA
Raw application message. What you're actually sending. Could be an HTTP request, email body, or file content.

L4 SEGMENT
Data + TCP/UDP header. Contains port numbers and sequence info. TCP splits big data into multiple segments.
↓
📫
L3 PACKET
Segment + IP header. Contains IP addresses. Routers READ this layer — they examine the destination IP and forward accordingly.
↓
🖼️
L2 FRAME
Packet + Ethernet header & FCS trailer. Contains MAC addresses. Switches READ this — they forward by MAC address on local network.
↓
⚡
L1 BITS
Everything as raw 0s and 1s. Transmitted as voltage, light or radio. No header — just the raw signal of all the layers stacked.

⚠ ATTACKS TARGET SPECIFIC LAYERS
L3 — IP
IP spoofing — forge the source IP in the packet header to hide identity or impersonate.
L4 — TCP
SYN flood — send thousands of TCP SYN segments, never completing the handshake.
L2 — MAC
ARP poisoning — send fake ARP frames to redirect traffic to the attacker's MAC.
