CONTROL #1: LOCK IT DOWN
SERVER ROOMS · TAMPER SEALS · ACCESS LOGS
PHYSICAL LAYER ZERO
SERVER ROOM CONTROLS
01
Locked server room with badge + PIN 2FA. Tailgating is the #1 bypass — use mantraps (two-door airlocks) so only one person enters per auth event.
02
Tamper-evident seals on chassis screws, cable access panels, and SFP cages. If broken, the sticker shows visible destruction — cannot be resealed invisibly.
03
Access logs on every entry: badge swipe timestamps + CCTV. Correlate with change tickets. An engineer who entered at 2am but filed no ticket is an anomaly.
04
Rack-level locks and cable locks on individual servers. Visitor access = escorted only. Cleaners and HVAC contractors are the most overlooked threat vector.
✓ IMPLEMENTATION CHECKLIST
Mantrap entry · Badge + PIN 2FA · CCTV at every rack aisle · Tamper seals on all chassis · Visitor log book · Rack-level cable locks · Motion sensors after-hours

CONTROL #2: DARK PORTS
DISABLE UNUSED SWITCH PORTS + PORT SECURITY
SWITCH CONFIG
24-PORT SWITCH — BEFORE / AFTER
SW01# conf t
! Shutdown all unused ports
SW01(config)# int range fa0/1-24
SW01(config-if)# shutdown
SW01(config)# int fa0/3
! Enable only needed ports
SW01(config-if)# no shutdown
SW01(config-if)# switchport mode access
SW01(config-if)# switchport port-security
SW01(config-if)# switchport port-security max 1
! Only 1 MAC allowed. New MAC = port shuts down.
01
Default: every port on a new switch is enabled. An attacker plugs into any open port and is on your network instantly. No auth. No log.
02
Port security limits the number of MAC addresses per port. Set to 1. If a second MAC appears (rogue device or hub), the port shuts down immediately.
03
Violation modes: shutdown (port off, log generated) · restrict (drop frames, log) · protect (drop silently — don't use this one).
✓ RULE OF THUMB
If a port has no device plugged in, it must be shutdown in config. Review quarterly. 802.1X adds auth on top — MAC alone is spoofable.
PORT SECURITY
Shut down every port you don't own
Default open ports are how laptop-in-a-closet attacks go undetected for months. One command per port, zero cost, massive reduction in attack surface.

CONTROL #3 + #4: FIBER + OTDR
TAP-RESISTANT CABLE · OPTICAL DETECTION
CABLE DETECTION
FIBER vs COPPER — TAPABILITY
OTDR — OPTICAL TIME-DOMAIN REFLECTOMETER
01
Copper wire can be tapped with a simple inductive clip — no cutting, no signal interruption. Takes 10 seconds and costs $20. Passive, silent.
02
Fiber optic must be physically bent or cut to tap. Bending causes measurable light loss. The signal is a beam — not an electrical field — so it can't be picked up inductively.
03
OTDR sends a laser pulse down the fiber and times the reflections. Taps create anomalies in the reflection signature — detectable within centimeters. Run monthly.
04
Set a baseline OTDR trace on day-1 of installation. Any future deviation alerts your NOC. NSA-grade taps are still detectable — optical loss can't be hidden.
FIBER ADVANTAGE
Light leaks are measurable. Copper leaks are invisible.
OTDR is the closest thing to a Layer 1 IDS. Baseline on install, schedule monthly scans, alert on any deviation >0.1 dB.
