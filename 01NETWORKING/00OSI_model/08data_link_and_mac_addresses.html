IEEE OUI REGISTRY LOOKUP
AA:BB:CC → INTEL CORPORATION
Every manufacturer registers their OUI with IEEE. Public database — anyone can look up who made a device from its MAC.
01
OUI (bytes 1–3) is assigned by IEEE to the manufacturer. Apple, Intel, Cisco each have their own. Over 47,000 OUIs registered globally. Never changes.
02
Device ID (bytes 4–6) is assigned by the manufacturer to each NIC. Must be unique within that manufacturer's OUI space. Usually sequential from the factory.
03
Byte 1, bit 0 = multicast flag. Byte 1, bit 1 = locally administered flag. If set, the MAC was software-assigned (MAC spoofing sets this bit).
04
MAC spoofing: OS can override the burned-in MAC. Attackers do this to bypass MAC filters or impersonate devices. The hardware MAC is called the BIA (Burned-In Address).

NODE-TO-NODE DELIVERY
LOCAL SEGMENT · BROADCAST MAC · ARP
DELIVERY LOCAL
UNICAST: ONE MAC → ONE MAC
BROADCAST: FF:FF:FF:FF:FF:FF
01
Unicast: frame has a specific destination MAC. The switch checks its CAM table, finds the port for that MAC, forwards only there. All other devices never see it.
02
Broadcast MAC FF:FF:FF:FF:FF:FF means "send to everyone on this segment." Used by ARP ("who has IP 192.168.1.5?") to discover MACs before first contact.
03
Multicast (01:00:5E:xx:xx:xx) targets a group — used by routing protocols (OSPF, IGMP) without flooding the entire segment like broadcast does.
04
Layer 2 only moves frames within the same broadcast domain. Hit a router → Layer 3 takes over. The switch strips the L2 header and wraps a new one per hop.
BROADCAST DOMAIN
FF:FF:FF:FF:FF:FF reaches every device on the LAN
Routers terminate broadcast domains. That's why a VLAN is a broadcast domain — traffic stays inside unless a router (or L3 switch) intervenes.

LAYER 1 — PHYSICAL
Bits sent as signals ↓
01
LLC (Logical Link Control) is the upper sublayer. It talks to Layer 3 and tells it: "here's data from Ethernet" or "here's data from Wi-Fi" — hides the physical medium.
02
MAC (Media Access Control) is the lower sublayer. It controls who gets to transmit on the shared medium. CSMA/CD for Ethernet. CSMA/CA for Wi-Fi.
03
LLC uses SAP (Service Access Point) codes to tell the receiver which Layer 3 protocol is inside: 0x06 = IP, 0xE0 = IPX. Like a type field telling you what's inside the box.
04
The split is why Ethernet and Wi-Fi can coexist — they share the same LLC sublayer but have completely different MAC sublayers. LLC is the common language up top.
TWO SUBLAYERS
LLC talks up. MAC talks down.
LLC abstracts the medium so Layer 3 doesn't care if it's Ethernet or Wi-Fi. MAC handles the physical medium access — the "who talks when" problem.

MINIMUM FRAME SIZE
64 bytes min 1518 bytes max (standard)
01
A frame = an IP packet wrapped with an L2 header (DST+SRC MAC + EtherType) and trailer (FCS). Layer 2 adds the envelope around Layer 3's letter.
02
EtherType (0x0800) tells the receiving NIC which protocol is inside the payload — so it knows whether to hand it up to the IPv4 or IPv6 stack.
03
FCS (CRC-32) is computed over the entire frame. Recipient recalculates it. If it doesn't match, the frame is silently dropped — no retry at Layer 2 (TCP handles that).
04
At each router hop, the L2 frame is stripped and a new one is built with new src/dst MACs for the next segment. The IP packet inside stays untouched end-to-end.
ENCAPSULATION
Frame wraps packet. Packet wraps segment.
Every layer wraps the one above. L2 adds MACs and FCS. L1 turns it into bits. On receive, each layer unwraps and passes up. This is encapsulation.
