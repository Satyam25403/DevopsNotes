git init    =>initialise empty git repo in current working directory...(.git/ hidden directory with all necessary configs and requirements).

git status  =>Shows tracked/untracked files, and whether changes are staged or not.

git add .(or)<filename>         =>add untracked files to staging area(track the untracked)

git commit -m "message here"    =>after adding to staging area...command to make commit
Records a snapshot of the staged changes in the repo history.

git log                 =>Shows all commits with their IDs(commit hash-uuid), author, date, and messages.

git restore --staged <filename>         =>to remove the file that has been added to staging area accidentally(using git add)

git diff <commit hash>          =>shows difference between the commit where head is and the specified commit hash

git reset --hard <commit hash>      =>head back to some commit in the commit history undoing all commits committed after that one

git remote add origin <git@github.com:.....git>(git uri)             =>add a remote(github/gitlab/bitbucket or any other git provider) repo to local repository

git push        =>push committed changes to remote repo
git push <origin_name> <branch_name>

git switch <branch_name>        =>switch to some branch
