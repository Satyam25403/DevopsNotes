THE 3 CULPRITS
① BULK READS
SELECT * dumps millions of rows into cache.
Each row used once, then never again.
② BACKGROUND JOBS
Nightly batch jobs read every record,
flooding cache with stale report data.
③ WRITE-THROUGH NO FILTER
Every write cached indiscriminately.
Rare-access records crowd out hot data.

BYPASS CACHE
① BE SELECTIVE
Don't cache everything. Cache data that will be read again soon. Ask: "will this be re-accessed in the next N minutes?"
② SHORT TTL FOR BULK READS
If you must cache bulk results, give them a very short TTL (30s–5min) so they expire before evicting hot data.
③ BYPASS FOR BATCH JOBS
Background jobs should query the DB directly with cache.SKIP flag, or use a read replica — never pollute prod cache.
