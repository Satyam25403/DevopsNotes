▸ when writing a cache key, register its tags
# cache the value
SET product:42:detail {...} EX 3600
# register key under tags
SADD tag:product:42 "product:42:detail"
SADD tag:category:elec "product:42:detail"
KEY INSIGHT
one key can belong to MULTIPLE tags.
invalidating any tag clears all its members.
you never hardcode key names at delete time.
SADD tag:product:42 "cache-key-name"
at write time, register the key under each tag.
at invalidation time, just name the tag.

ATOMIC INVALIDATION (Lua script)
# get all members of tag set
local keys = redis.call('SMEMBERS', KEYS[1])
for _, k in ipairs(keys) do
  redis.call('DEL', k)
end
redis.call('DEL', KEYS[1]) -- drop tag set too
SMEMBERS tag:product:42 → DEL each member
one Lua script: fetch tag set → delete all keys.
atomic. no race conditions. O(N) where N=keys.

⚠ WATCH OUT
tag sets grow if keys expire without cleanup.
use Lua to delete the tag set itself on invalidation.
or: expire tag sets with a TTL slightly longer than members.
write = SET key + SADD tag key
invalidate = SMEMBERS tag → DEL all + DEL tag.
one Lua script. works for any number of keys.
