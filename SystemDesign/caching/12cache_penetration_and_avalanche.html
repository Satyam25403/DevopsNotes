AVALANCHE FIX SOLUTION
FIX 1: TTL JITTER
Add randomness to TTL so keys don't all
expire at the same second.
// BEFORE — synchronized (dangerous):
cache.set(key, val, ttl=3600);

// AFTER — with jitter (safe):
jitter = random(0, 600); // ±10min
cache.set(key, val, ttl=3600 + jitter);
EXPIRY DISTRIBUTION WITH JITTER
t=3600spread evenly over 600st=4200
✓ ~7 expirations/sec instead of 10,000 at once
FIX 2: CIRCUIT BREAKER
If DB error rate exceeds threshold,
trip the breaker — reject requests fast,
let DB recover before re-enabling.
