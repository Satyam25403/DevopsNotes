METRICS · ROOT CAUSES · FIXES
DIAGNOSE ROOT CAUSE
▸ symptom → root cause → fix
① HIT RATIO DROPS
ROOT CAUSE
cache pollution (junk data evicting hot keys), wrong TTL, keys never populated, cold start after deploy
FIX
separate namespaces, tune TTLs, add cache warming on deploy, check eviction policy
② EVICTION RATE SPIKES
ROOT CAUSE
cache too small for dataset, TTLs too long locking memory, wrong policy (allkeys-random evicts hot data)
FIX
increase maxmemory, switch to allkeys-lru, shorten TTLs on low-value keys
③ MEMORY APPROACHING MAX
ROOT CAUSE
dataset growth, TTL too long, no eviction policy set (noeviction = OOM errors)
FIX
scale Redis instance, set maxmemory-policy, alert at 85% not 100%
④ P99 LATENCY SPIKE
ROOT CAUSE
large value serialization, slow O(N) commands (KEYS, SMEMBERS on big sets), network jitter, memory swap
FIX
use SCAN not KEYS, limit value size, disable swap, use pipelining for batches

▸ prometheus alert rules
# alert.rules.yml
- alert: CacheHitRatioLow
expr: redis_keyspace_hits / (redis_keyspace_hits + redis_keyspace_misses) < 0.8
for: 5m
- alert: CacheEvictionHigh
expr: rate(redis_evicted_keys_total[1m]) > 100
for: 2m
