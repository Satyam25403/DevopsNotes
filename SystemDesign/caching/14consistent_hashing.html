CONSISTENT HASHING SOLUTION
Place nodes on a virtual ring (0–2³²).
Keys route to the next node clockwise.
Add 1 node → only 1/N keys remap.
N=4: only 25% move instead of 100%.

PROBLEM: UNEVEN ARCS
3 nodes on ring → arcs not equal.
One node gets 40% of keys, another 20%.
Fix: Virtual Nodes (VNodes) — each physical
node gets multiple positions on the ring.
WITH 3 VNODES EACH:
Node A → positions: 12, 156, 289 on ring
Node B → positions: 67, 198, 341 on ring
Node C → positions: 118, 234, 356 on ring

REDIS CLUSTER: 16,384 HASH SLOTS
Redis doesn't use a pure ring.
It uses 16,384 fixed hash slots.
slot = CRC16(key) % 16384
Each node owns a range of slots.
Node A: slots 0 – 5460
Node B: slots 5461 – 10922
Node C: slots 10923 – 16383
