Jenkins is an open-source automation server that helps developers and DevOps teams build, test, and deploy 
software continuously. It’s the backbone of many CI/CD pipelines, allowing you to automate everything from 
compiling code to pushing it live. 

⚙️ Jenkins Setup Overview(do this inside a server like ec2 or gcp's compute service->ssh into it and then proceed)
Here’s a quick guide to getting Jenkins up and running:

follow these steps for some ubuntu instance: (jenkins requires java)
java -version
sudo apt update 
sudo apt install openjdk-11-jdk -y
curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io.key | sudo tee /usr/share/keyrings/jenkins-keyring.asc > /dev/null           (importing the key)
echo deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] https://pkg.jenkins.io/debian-stable binary/ | sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null       (adding it to key-ring)
sudo apt update
sudo apt install jenkins -y
sudo systemctl status jenkins 
sudo cat /var/lib/jenkins/secrets/initialAdminPassword

u can now open <that_instance_ip>:8080

Localsetup:
🖥️ 1. Install Jenkins
- Linux/macOS: Use apt, yum, or brew
- Windows: Download the installer from jenkins.io
- Docker:
docker run -it -p 8080:8080 -p 50000:50000 jenkins/jenkins:lts

🔐 2. Unlock Jenkins
- After installation, visit http://localhost:8080
- Enter the initial admin password from:
/var/lib/jenkins/secrets/initialAdminPassword

🧩 3. Install Plugins
- Jenkins will prompt you to install recommended plugins (Git, Maven, Docker, etc.)
- You can add more later via Manage Jenkins → Plugins

👤 4. Create Admin User
- Set up your first user and configure basic security settings

By now jenkins is good to go...

🔄 Jenkins in CI/CD
Jenkins can:
- Pull code from GitHub/GitLab
- Run tests and linters
- Build Docker images
- Deploy to Kubernetes or cloud providers
- Send notifications via Slack, email, etc.
You can orchestrate all this using Jenkins Pipelines, written in Jenkinsfile using Groovy syntax.
