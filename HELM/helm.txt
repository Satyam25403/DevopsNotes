similar to windows: choco, mac: brew, ubuntu: apt, redhat: yum and all package managers

HELM: package manager for kubernetes

why we need it?
let us say we need to install ARGOCD(let a cicd tool)
1.traditional way=>download binaries=>follow instructions
2.if we install it as pod kubernetes=>we need to manage seprate deployment, service, role/binding, policies, namespace
and all other yamls manually

SOLUTION: HELM=>bundles all these together whatever we specified above...deployment, service, policies etc => collectively called as HELM CHART
the chart is stored on helm REPOSITORY...artifacts.io   -> central repo for charts
when we need to install the package...we pull chart from repo and create a RELEASE(running instance) out of it

charts are reusable -> single chart into multiple environments
each time we deploy a chart -> a new release is created
