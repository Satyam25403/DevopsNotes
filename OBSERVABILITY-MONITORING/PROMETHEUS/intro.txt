# 3️⃣ Loki Roadmap (Logs Monitoring)

Grafana Loki

Loki is used for **centralized logging**.

It is similar to **Elasticsearch**, but cheaper.

---

## Phase 1 — Core Concepts

Write notes on:

* Centralized logging
* Log aggregation
* Labels vs indexing
* Loki architecture

Components:

```
Loki
Promtail
Grafana
```

---

## Phase 2 — Promtail

Promtail collects logs and sends them to Loki.

Topics:

* Log scraping
* Labels
* Log pipelines

Example:

```
/var/log/syslog
/var/log/nginx/access.log
```

---

## Phase 3 — LogQL

LogQL = Loki Query Language

Similar to PromQL.

Example:

```
{job="nginx"}
```

Filtering:

```
|= "error"
```

Regex search:

```
|~ "timeout"
```

---

## Phase 4 — Log Pipelines

Learn:

* Parsing logs
* Regex extraction
* JSON parsing
* Label creation

Example logs:

```
nginx logs
docker logs
application logs
```

# 4️⃣ Integrating Prometheus + Grafana + Loki

Final stage is combining them.

Architecture:

```
Servers / Containers
        ↓
Prometheus → Metrics
Loki → Logs
        ↓
Grafana
        ↓
Dashboards + Alerts
```

Example stack:

```
Node Exporter
Prometheus
Loki
Promtail
Grafana
```
