🧰 Jenkins Setup (Local or EC2)
You can install Jenkins either on your local machine or directly on the EC2 instance where your app runs. Here's how to set it up:
sudo apt update
sudo apt install openjdk-11-jdk -y
curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io.key | sudo tee /usr/share/keyrings/jenkins-keyring.asc > /dev/null
echo deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] https://pkg.jenkins.io/debian-stable binary/ | sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null
sudo apt update
sudo apt install jenkins -y

Start Jenkins:
sudo systemctl start jenkins
sudo systemctl enable jenkins

Give Jenkins server access to Docker(most important step):
sudo usermod -a -G docker jenkins
sudo systemctl restart jenkins

Access Jenkins at: http://<your-ec2-ip>:8080

🔐 2. Unlock Jenkins
sudo cat /var/lib/jenkins/secrets/initialAdminPassword

🛠️ 4. Create a Jenkins Job
Choose Pipeline or Freestyle Project. 

Freestyle project(GUI):
follow prompts -> use github as SST(single source of truth)/SCM (source code management) -> specify repo link(username and password in credentials if private repo)
choose build triggers(when to trigger): mostly poll SCM(i.e. whenever a new push into repo is done) -> cron schedule (5 stars(cron expression for checking every minute))
choose (execute shell) -> and paste these commands
docker stop edward
docker rm edward
docker build -t .           (because it will clone and we will be already in same directory)
docker run --name edward -d -p 9000:9000 edward
save        -> u can modify above settings in config

For a basic pipeline:
pipeline {
  agent any

  environment {
    DOCKER_IMAGE_NAME = "edward"
    DOCKER_PORT       = "9000"
  }

  stages {
    stage('Clone Repo') {
      steps {
        git credentialsId: 'your-creds-id', url: 'https://github.com/your-org/your-private-repo.git'
      }
    }

    stage('Stop & Remove Existing Container') {
      steps {
        sh '''
          docker stop edward || true
          docker rm edward || true
        '''
      }
    }

    stage('Build Docker Image') {
      steps {
        sh 'docker build -t edward .'
      }
    }

    stage('Run Container') {
      steps {
        sh 'docker run --name edward -d -p 9000:9000 edward'
      }
    }
  }

  post {
    success {
      echo "App deployed successfully at http://<your-ec2-ip>:9000"
    }
    failure {
      echo "Deployment failed. Check logs above."
    }
  }
}
