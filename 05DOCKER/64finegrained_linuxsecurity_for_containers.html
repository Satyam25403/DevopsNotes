DOCKER DEFAULT SECCOMP
Blocks: ptrace, mount, kexec, pivot_root
Allows: read, write, open, close, fork
Enabled by default on Docker ≥ 1.10
~300 syscalls blocked out of 400+
terminal
# use default profile (explicit)
$ docker run --security-opt \
seccomp=default nginx
# custom profile
$ docker run --security-opt \
seccomp=profile.json nginx
# disable (dangerous!)
$ docker run --security-opt \
seccomp=unconfined nginx
seccomp works below capabilities — kernel-level syscall allowlist.
Never use seccomp=unconfined in production. Ever.

profile docker-nginx flags=(attach_disconnected) {

AppArmor = file path + network + capability rules per process.
Three layers: capabilities → seccomp → AppArmor. All independent.
