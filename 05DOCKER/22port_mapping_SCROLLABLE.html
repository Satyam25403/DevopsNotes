NETWORK ISOLATION
WHY IT FAILS
Docker containers run in their own network namespace. Nginx binds to port 80 inside the container — but that's invisible to your host OS. There's no path in.
Nginx is healthy inside the container — it just can't be reached.
Container networks are isolated from the host by default.

⚠ GOTCHA: PORT ALREADY IN USE
If 8080 is taken, pick any other host port: -p 9090:80. The LEFT side is yours to choose. The RIGHT side must match what's inside the image.
★ MULTIPLE PORTS
Stack -p flags for multi-port apps:
-p 8080:80 -p 8443:443
Each flag maps exactly one port pair.
verify mappings
$ docker ps

Left = host port (your choice). Right = container port (app's choice).
Use docker ps or docker port to verify your mapping is live.
