SEMANTIC VERSIONING TAGS
:1.0.0 exact release — immutable, safe for prod
:1.0 minor float — gets patch updates
:1 major float — gets minor + patch
:latest default if no tag — avoid in prod!
:dev / :staging env-based tags for CI pipelines
⚠ NEVER USE :latest IN PRODUCTION
:latest is mutable — a new push overwrites it.
Your "stable" deploy can silently change.
Always pin to an exact version tag.
username/repo:tag — three parts, one identity.
Pin exact versions in prod. Never rely on :latest.
