🛡 THE FIX: DOCKERFILE
USER INSTRUCTION + ADDUSER + --CHOWN
✓ HARDENING HARDEN NOW
✗ BEFORE — Dockerfile (dangerous)
FROM node:18-alpine
WORKDIR /app
COPY . .
RUN npm install
CMD ["node", "server.js"]
# Running as root! uid=0
✓ AFTER — Dockerfile (safe)
FROM node:18-alpine
WORKDIR /app
RUN addgroup -S appgroup \
  && adduser -S appuser -G appgroup
COPY --chown=appuser:appgroup . .
RUN npm install
USER appuser # ← non-root!
CMD ["node", "server.js"]
KEY INSTRUCTIONS:
addgroup -S → system group, no login
adduser -S → system user (no passwd)
--chown → files owned by appuser
USER → switch before CMD/ENTRYPOINT
verify it worked
$ docker exec myapp whoami
appuser
$ docker exec myapp id
uid=100(appuser) gid=101(appgroup)
adduser + USER directive drops privileges before your app ever starts.
Even if exploited: attacker gets uid=100, not uid=0. Blast radius contained.
