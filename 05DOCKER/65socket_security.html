⚠ DinD WITH --privileged IS ALSO BAD

KANIKO GOOGLE / K8S
Builds images from a Dockerfile entirely in userspace. No docker daemon. No socket. Runs as an unprivileged container. Made for Kubernetes.
docker run gcr.io/kaniko-project/executor \
--context=dir:///workspace \
--no-push # no socket needed
BUILDAH REDHAT / OCI
OCI-native image builder. Rootless by default. Uses user namespaces. Pairs with Podman. Understands Dockerfiles natively.
buildah bud -t myapp:latest . # rootless
buildah push myapp:latest \
docker://registry.io/myapp:latest
SYSBOX / ROOTLESS DinD NESTABLE
Sysbox runtime allows nested containers without --privileged. Uses user namespaces. Rootless DinD with docker:dind-rootless image works for simple cases.
Kaniko and Buildah build images with zero daemon contact.
No socket mount. No --privileged. No host exposure.
