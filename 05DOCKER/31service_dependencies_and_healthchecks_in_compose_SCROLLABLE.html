🔬 HEALTHCHECK ANATOMY
test — command to run (exit 0 = healthy)
interval — how often to probe (5s)
timeout — max time per probe (3s)
retries — fails before unhealthy (5)
start_period — grace window for init (15s)
start_period gives MySQL time to initialise without counting failures.
Compose won't start backend until DB probe returns exit 0.

⚠️ COMMON GOTCHAS
• Omit start_period → fails during init
• Skip healthcheck block → condition ignored
• CMD vs CMD-SHELL: shell expands $$ vars
• Swarm needs HEALTHCHECK in Dockerfile too
service_completed_successfully is perfect for one-shot migration containers.
All three conditions work together in depends_on.
