WHY docker top
See every process without entering the container. Spot zombie processes, unexpected shells, or runaway loops that explain high CPU in docker stats. Pass ps flags for more detail: docker top api aux

"DB_URL=postgres://..."]}

KEY SECTIONS IN INSPECT OUTPUT
State Running/exited status, exit code, restart count, OOM killed flag. RestartCount > 0 means it's been crashing.
Mounts Every volume/bind mount. Source on host → Destination in container. Verify the right directories are wired up.
NetworkSettings Container IP, port bindings, network membership. Confirm exposed ports are mapped correctly.
Config.Env All env vars the container sees. Debug missing vars, wrong DB URLs, or leaked secrets.
surgical inspect — use --format
$ docker inspect api \
--format '{{.State.RestartCount}}'
4
$ docker inspect api \
--format '{{.NetworkSettings.IPAddress}}'
172.18.0.3
