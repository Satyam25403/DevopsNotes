😤 BIND MOUNT PROBLEMS
• Root owns files → can't edit on host
• macOS / Windows path translation bugs
• node_modules leaks from host into container
• Works on my machine™, breaks in CI
THE PERMISSION MESS
✨ COMPOSE WATCH FIXES THIS
No volume mounts needed. Watch copies files
into the container on save. You own the host
files. Container owns its own copy. No conflict.
Bind mounts share the inode — uid mismatch poisons everything.
Compose Watch copies files. No sharing. No conflict.

- action: rebuild
path: package.json
- action: sync+restart
path: .env
target: /app/.env
⚡ sync ~50ms
Copy changed file into running container. No restart. Fastest — use for src/, templates, CSS.
🔨 rebuild full build
Trigger docker build + replace container. Use for package.json, Dockerfile, go.mod changes.
🔄 sync+restart ~1-2s
Sync file then restart the process (not rebuild image). Perfect for .env, config files that need re-read.
develop.watch lives inside the service block — no volumes needed.
