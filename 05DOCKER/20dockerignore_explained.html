WORKDIR /app
COPY package*.json ./
RUN npm ci # installs fresh inside
COPY . . # fast — no node_modules
CMD ["node","index.js"]
⚠ COMMON MISTAKE
COPY . . before RUN npm ci
means you copy node_modules in
even if .dockerignore excludes them.
Always COPY package.json first,
RUN install, THEN COPY . .
Same level as Dockerfile. Works like .gitignore.
Copy package.json → install → COPY . . is the pattern.
