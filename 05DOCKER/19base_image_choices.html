ALPINE GOTCHA
SMALLER ≠ ALWAYS BETTER
COMPAT WARNING ⚠ READ THIS
⚠️
ALPINE USES musl libc — NOT glibc
Most Linux apps expect GNU libc (glibc).
Alpine ships musl — a smaller but different impl.
Many npm native modules break silently.
COMMON ALPINE BREAKAGE
✗
node-gyp native addons (bcrypt, canvas, sharp)
✗
glibc-linked binaries (some Python C extensions)
✗
Slower DNS resolution in some setups (musl quirk)
✗
Missing debugging tools (bash, curl, etc.)
ALPINE WORKS GREAT FOR
✓
Pure JS / TypeScript apps (no native modules)
✓
Go binaries (statically linked, no libc issue)
✓
Simple scripts, proxies, static file servers
