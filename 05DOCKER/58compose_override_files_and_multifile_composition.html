THE TYPICAL TRAP
❌ One giant docker-compose.yml
with if/else env vars everywhere
❌ Bind mounts leaking into prod
./src:/app in production = bad
❌ Debug ports open in CI
5005:5005 exposed always
✅ THE SOLUTION
Split into base.yml + environment-specific overrides.
Docker merges them at runtime — no duplication, clean separation.
One base file. Many environment overrides.
Docker deep-merges them — keys override, lists append.

docker-compose.override.yml
MAGIC FILE AUTO-MERGE
🪄 AUTOMATIC MAGIC
If a file named docker-compose.override.yml exists in the same directory, Docker Compose merges it automatically. No flags needed — just docker compose up.
docker-compose.yml
services:
web:
image: myapp:latest
ports: ["80:80"]
environment:
NODE_ENV: production
docker-compose.override.yml
services:
web:
volumes:
- ./src:/app # bind mount
environment:
NODE_ENV: development
ports: ["5005:5005"] # debug
terminal
$ docker compose up
# auto-merges override.yml ✓
# NODE_ENV=development wins
# bind mount + debug port added
docker-compose.override.yml merges automatically.
Perfect for local dev defaults — no flags needed.

MERGE RULES
🔑 Scalar values → override wins
📋 Lists (ports/volumes) → append
🗺️ Maps (environment) → deep merge
❌ To remove a key → use null
terminal
$ docker compose \
-f docker-compose.yml \
-f docker-compose.prod.yml \
up -d
Dev gets bind mounts + debug ports. Prod gets resource limits.
Never mix env concerns in one giant compose file.

CI PIPELINE STEP
$ docker compose \
-f docker-compose.yml \
-f docker-compose.ci.yml \
up --abort-on-container-exit
# exits when tests complete ✓
⚡ CI-SPECIFIC TRICKS
tmpfs for DB = fast, disposable, no disk I/O
$CI_COMMIT_SHA pins exact image per build
--abort-on-container-exit auto-cleanup
No bind mounts — CI has no local src dir
CI gets ephemeral DB, pinned image SHA, no mounts.
--abort-on-container-exit cleans up after tests.

  --abort-on-container-exit
# validate merged config
docker compose -f base.yml -f prod.yml config
💡 PRO TIP: config COMMAND
Run docker compose ... config to print the fully merged YAML before deploying. Catches merge surprises before they hit production.
One base + N override files = clean environment separation.
Run docker compose config to verify merged output.
