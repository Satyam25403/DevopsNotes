⚡ ARG-TO-ENV TRAP
ARG TOKEN → ENV TOKEN=$TOKEN defeats the purpose. Now it's baked in. Don't copy ARG values into ENV.
QUICK RULE:
ARG → build-time tokens, never secrets
ENV → non-secret config (PORT, NODE_ENV)
-e flag → runtime secrets, NOT in image
ARG values vanish after build. ENV values live in every layer forever.
Never copy an ARG into an ENV. That negates all protection.
