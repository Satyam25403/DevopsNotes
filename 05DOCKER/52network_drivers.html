HOW BRIDGE WORKS
Each container gets a private IP on 172.17.0.0/16.
Outbound traffic is NATted via iptables.
Containers on same bridge can talk directly.
Expose ports with -p 8080:80 to reach from host.
BRIDGE COMMANDS
# default bridge (automatic)
docker run -p 8080:80 nginx
# custom bridge (recommended)
docker network create --driver bridge mynet
docker run --network mynet nginx
💡 CUSTOM BRIDGE > DEFAULT BRIDGE
Custom bridges get automatic DNS — containers reach
each other by name. Default bridge needs
--link (deprecated) or manual IPs.
Bridge = NAT-based private network per host.
Custom bridges get DNS. Default bridge does not.

HOW VXLAN ENCAPSULATION WORKS
Container packet → wrapped in VXLAN header
→ sent as UDP over physical network →
unwrapped on destination host → delivered
to container. Transparent to the app.
OVERLAY — REQUIRES SWARM MODE
# init swarm first
docker swarm init
# create overlay network
docker network create \
  --driver overlay myoverlay
# deploy service on it
docker service create \
  --network myoverlay nginx
USE OVERLAY WHEN
✓ Running Docker Swarm services
✓ Containers span multiple physical hosts
✓ Need service discovery across nodes
✗ Single host → use bridge instead
Overlay tunnels container traffic across hosts via VXLAN.
Requires Swarm mode. Uses UDP port 4789.
