Nginx (pronounced “engine-x”) is a high-performance, open-source web server that also functions as a reverse proxy, load balancer, and HTTP cache. 
It’s widely used to serve static content, route traffic to backend services, and handle SSL termination.

🚀 Common Use Cases:
• 	Hosting static websites (HTML, CSS, JS)
• 	Reverse proxying to backend apps (like Flask or Express)
• 	Load balancing across multiple servers
• 	SSL termination and HTTPS redirection
• 	Serving Docker containers via proxy


==================================================================================================================================================

Installation:

sudo apt update
sudo apt install nginx
sudo systemctl start nginx
