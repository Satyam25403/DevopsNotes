📁 Example 1: Serving Static Files Directly with Nginx
This setup is perfect for hosting HTML, CSS, JS, or image files without needing a backend server.
server {
    listen 80;
    server_name localhost;

    location / {
        root /var/www/html;
        index index.html;
    }
}

📝 What it does:
- Serves files from /var/www/html
- If a user visits http://localhost, Nginx will serve /var/www/html/index.html
- You can drop any static files (like style.css, script.js) in that directory and they’ll be accessible
🔧 Tip: Make sure the directory and files have proper read permissions for the Nginx user (www-data on Ubuntu).
listening on port 80 without redirecting to HTTPS leaves your app exposed
server {
    listen 80;
    server_name localhost;

    location / {
        return 301 https://$host$request_uri;
    }
}
🧠 What this does:
- Listens on port 80 (HTTP)
- For any request, it sends a 301 Moved Permanently response
- Redirects to the same host and URI, but over HTTPS
Make sure you have a separate server block listening on port 443 with SSL configured
server {
    listen 443 ssl;
    server_name example.com www.example.com;

    #specifies the SSL certificate location 
    ssl_certificate     /etc/nginx/ssl/your-cert.pem;
    ssl_certificate_key /etc/nginx/ssl/your-key.pem;

    location / {
        root /var/www/html;
        index index.html;
    }
}

🔀 Example 2: Reverse Proxy to a Backend Web Server
This is ideal when you want Nginx to sit in front of a Flask or Express app running on another port.
server {
    listen 80;
    server_name localhost;

    location / {
        proxy_pass http://127.0.0.1:3000;  # Node.js app running on port 3000
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}


📝 What it does:
- Requests to /api/ are forwarded to your Node.js app on port 3000
- Requests to / go to your Express app on port 3000
- Nginx handles incoming traffic and routes it to the correct service
