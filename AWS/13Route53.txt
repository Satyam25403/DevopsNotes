Amazon Route 53 is AWS’s highly available and scalable DNS (Domain Name System) web service. 
It’s named after port 53, which is the standard port for DNS traffic. Route 53 helps you manage domain names, 
route traffic to AWS resources, and monitor the health of your infrastructure.

Its like CloudFare provided by aws: allows u to manage your DNS
allows u to register new domains
once u registered ur domain, u can attach ur domain names to an AWS service like s3 etc directly

Domain Registration: You can register domain names directly through Route 53.
DNS Routing: Maps domain names to IP addresses or AWS resources (like EC2, S3, ELB).
Health Checks: Monitors endpoints and reroutes traffic if a resource becomes unhealthy.

🧪 Use Cases
- Hosting a website with a custom domain
- Load balancing across AWS regions
- Redirecting traffic during outages
- Integrating with CloudFront for global content delivery
- Managing DNS for hybrid cloud or private networks
