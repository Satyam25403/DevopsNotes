
🌐 What Is a CDN?       => Reduce latency
A Content Delivery Network (CDN) is a globally distributed network of servers that delivers web content to users based on their geographic location. 
Instead of fetching data from a central server every time, CDNs cache content at edge locations closer to the user—reducing latency, improving load times, 
and easing the load on origin servers.

This is because servers/databases cant be geographically everywhere...solution to this problem is CDN

Benefits of CDNs
- Faster load times for websites and apps
- Reduced bandwidth costs by caching static assets
- Improved availability and fault tolerance
- Enhanced security with DDoS protection and HTTPS support



🛠️ AWS CDN: Amazon CloudFront 
Amazon CloudFront is AWS’s managed CDN service. It integrates seamlessly with other AWS services 
like S3, EC2, Lambda@Edge, and API Gateway.

- u can choose some origin domain(ex: what data u need to serve ex:data on s3)
=> once created a CDN u just need its aws distribution domain name(but be sure that the origin ex:s3 bucket containing that data is publicly accessible)
=> also the files inside it (ex:s3) should have proper ACLs with allowed read/write permission

🔑 Key Features:
- 700+ edge locations worldwide for ultra-low latency
- HTTPS and TLS encryption for secure delivery
- Built-in DDoS protection via AWS Shield
- Custom logic at the edge using Lambda@Edge
- Real-time metrics and logging via CloudWatch
🧪 Use Cases:
- Accelerating static websites (HTML, CSS, JS)
- Streaming video (live or on-demand)
- Serving APIs and dynamic content
- Distributing software updates or game patches



🔍 How It Works
- User requests content (e.g., image, video, API).
- CloudFront routes the request to the nearest edge location.
- If cached, content is served instantly.
- If not cached, CloudFront fetches it from the origin server (e.g., S3, EC2).
- The content is cached for future requests.
