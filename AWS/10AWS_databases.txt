🔑 Core AWS Database Services
1. Amazon RDS (Relational Database Service)
One stop solution for relational db on AWS
Fully managed relational databases.
Supports: MySQL, PostgreSQL, MariaDB, Oracle, SQL Server, and Amazon Aurora.
Handles backups, patching, and scaling for you.

2. Amazon Aurora
Cloud-native relational database compatible with MySQL and PostgreSQL.
Faster and more scalable than traditional RDS engines.
Great for high-performance applications.

3. Amazon DynamoDB
Fully managed NoSQL key-value and document database.
Single-digit millisecond latency.
Serverless, auto-scaling, and good for massive workloads like gaming, IoT, and ad tech.

4. Amazon Redshift
Managed data warehouse for analytics.
Optimized for running SQL queries across large datasets.
Commonly used for BI (Business Intelligence) and reporting.

5. Amazon ElastiCache
In-memory cache service.
Supports Redis and Memcached.
Boosts app performance by reducing database load.

6. Amazon DocumentDB
Managed document database compatible with MongoDB workloads.
Designed for JSON-like document storage.

7. Amazon Neptune
Fully managed graph database.
Supports property graph and RDF models.
Used in fraud detection, recommendation engines, and social networks.

8. Amazon Keyspaces
Managed Apache Cassandra-compatible service.
Great for large-scale, low-latency workloads.

9. Amazon Timestream
Time-series database.
Ideal for IoT telemetry, app monitoring, and real-time analytics.

10. Amazon QLDB (Quantum Ledger Database)
Immutable ledger database.
Cryptographically verifiable transaction history.
Useful in finance, supply chain, and compliance apps.

11. AWS Glue Data Catalog
Technically not a DB, but a metadata catalog.
Helps organize and discover datasets across AWS.

👉 In short:
RDS / Aurora → Relational apps.
DynamoDB → NoSQL, high-speed workloads.
Redshift → Analytics at scale.
ElastiCache → Speed boost via caching.
Neptune → Graph relationships.
Timestream → IoT/time-series data.
QLDB → Immutable ledger.
Keyspaces → Cassandra workloads.
