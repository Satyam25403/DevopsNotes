AWS Command Line Interface (CLI) is a powerful tool that lets you interact with AWS services directly from your terminal 
perfect for developers, sysadmins, and cloud engineers who want to automate tasks, script deployments, or just move faster

What You Can Do with AWS CLI
- Manage AWS resources: EC2 instances, S3 buckets, IAM users, Lambda functions, and more
- Automate workflows: Use shell scripts or CI/CD pipelines to deploy infrastructure
- Query and filter data: Get JSON outputs and use JMESPath to extract what you need
- Switch profiles and regions: Easily work across multiple AWS accounts

1. Install AWS CLI v2 =>see documentation
linux:
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install

windows:
msiexec.exe /i https://awscli.amazonaws.com/AWSCLIV2.msi

Verify installation:
aws --version

2. Configure Your Credentials
aws configure

You'll be prompted for:
- AWS Access Key ID
- AWS Secret Access Key
- Default region (e.g., us-east-1)
- Output format (json, text, or table)

for any env 3 variables are needed for configuring aws cli:(ex for linux)
export AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
export AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
export AWS_REGION=us-west-2

🧪 Example Commands
aws s3 ls                # List all S3 buckets
aws ec2 describe-instances --region us-west-2
aws lambda invoke --function-name myFunction output.json


You can even use aws help or aws ec2 help to explore commands interactively.
