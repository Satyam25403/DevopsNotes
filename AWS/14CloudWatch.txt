AWS solution to logging, monitoring and alarms designed to give you deep visibility into your infrastructure and applications.

🔍 What CloudWatch Does
Metrics: Tracks performance data like CPU usage, memory, disk I/O, latency
Logs: Collects and stores logs from EC2, Lambda, containers, and custom apps
Alarms: Triggers notifications or actions when metrics cross thresholds
Dashboards: Visualizes metrics and logs in real-time
Events: Responds to changes in AWS resources (e.g., EC2 state changes)
Insights: Analyzes logs with queries for debugging and auditing

🧠 How It Works
• 	You publish metrics and logs from AWS services or custom sources.
• 	CloudWatch stores and visualizes this data.
• 	You can set alarms to notify you or trigger actions (e.g., auto-scaling, Lambda).
• 	You can query logs using CloudWatch Logs Insights for deep analysis.

🛠️ Example Use Cases
• 	Monitor EC2 CPU and memory usage
• 	Alert when S3 bucket access spikes
• 	Debug Lambda errors using log filters
• 	Auto-scale ECS tasks based on request count
• 	Visualize API Gateway latency in dashboards
