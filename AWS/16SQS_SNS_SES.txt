
📬 Amazon SQS (Simple Queue Service)
A fully managed message queue that enables asynchronous communication between distributed systems.
- Model: Pull-based (consumers poll the queue)
- Use Cases:
- Decouple microservices
- Buffer tasks for worker queues
- Handle traffic spikes gracefully
- Features:
- FIFO and Standard queues
- Dead-letter queues
- Message retention and visibility timeout

📣 Amazon SNS (Simple Notification Service)
A pub/sub messaging service that pushes notifications to multiple subscribers instantly.
- Model: Push-based (messages sent to subscribers)
- Use Cases:
- Fan-out architecture (e.g., notify multiple systems)
- Mobile push notifications
- Email/SMS alerts
- Features:
- Topic-based messaging
- Message filtering
- Integrates with Lambda, SQS, HTTP endpoints

====================================================================================================

📧 Amazon SES (Simple Email Service)
A cloud-based email service for sending and receiving emails at scale.
- Model: SMTP or API-based
- Use Cases:
- Transactional emails (e.g., password resets, receipts)
- Marketing campaigns
- Email-based alerts
- Features:
- High deliverability
- DKIM, SPF, DMARC support
- Bounce and complaint tracking
