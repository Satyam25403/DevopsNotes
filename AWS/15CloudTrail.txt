AWS CloudTrail is a service that provides visibility into user activity and API usage across your AWS infrastructure. It’s designed for security auditing, compliance, and operational troubleshooting.

🔍 What CloudTrail Tracks
- Who made the request (user, role, service)
- What action was taken (e.g., StartInstances, PutObject)
- When it happened (timestamp)
- Where it came from (IP address, region)
- Which resources were affected

It records events from:
- AWS Management Console
- AWS CLI
- SDKs and APIs

🧠 Key Components
| Event History   | Viewable log of the last 90 days of management events (free) | 
| Trails          | Deliver logs to S3, CloudWatch Logs, or EventBridge for long-term storage | 
| CloudTrail Lake | Managed data lake for querying and analyzing events at scale | 

🛠️ Use Cases
- Security auditing: Who accessed what and when
- Compliance: Track changes for governance and regulatory needs
- Troubleshooting: Investigate failed API calls or unexpected behavior
- Automation triggers: Use EventBridge to respond to specific actions

🔐 Bonus Features
- Multi-account logging via AWS Organizations
- Insights for detecting unusual API activity
- Integration with Athena, CloudWatch, and third-party SIEMs
