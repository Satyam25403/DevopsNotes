Amazon S3 (Simple Storage Service) is AWS’s flagship object storage service, designed for storing and retrieving any amount of data from anywhere on the web
it is a type of block storage(analogous to a filesystem)


📦 Key Features of Amazon S3
- Object Storage: Stores data as objects (files + metadata) inside buckets.
- Unlimited Scalability: You can store petabytes of data — no provisioning needed.
- High Durability: 99.999999999% (11 nines!) durability across multiple Availability Zones.
- Flexible Access: Access via AWS Console, CLI, SDKs, or REST API.
- Fine-Grained Permissions: Control access using IAM policies, bucket policies, ACLs.
- Versioning: Keep multiple versions of an object for recovery or auditing.

🧠 Common Use Cases
- 🗃️ Backup & Restore: Store snapshots, logs, and disaster recovery data.
- 🌐 Static Website Hosting: Serve HTML/CSS/JS directly from S3.
- 📊 Data Lakes: Centralize structured and unstructured data for analytics.
- 🧬 Machine Learning: Store training datasets and model outputs.
- 🧾 Archiving: Use S3 Glacier for long-term, low-cost storage


🧰 Storage Classes:
S3 Standard => Frequent access
S3 Intelligent-Tiering => Auto-adjusts based on usage
S3 Glacier => Archival, retrieval in minutes/hours
S3 Glacier Deep Archive => Lowest cost, retrieval in hours


🛠️ How to Use S3
- Create a Bucket: Your top-level container for objects.
- Upload Files: Drag-and-drop via console or use CLI:
aws s3 cp myfile.txt s3://my-bucket-name/
- Set Permissions: Use bucket policies or IAM roles.
- Access Objects: Publicly or via signed URLs.
