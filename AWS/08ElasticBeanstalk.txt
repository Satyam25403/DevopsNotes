Bare minimums for an app:
system: os, cpu, memory
runtime: python, node, java
web server: nginx, apache etc


Elastic Beanstalk:
it’s a full-fledged Platform-as-a-Service (PaaS) that provisions everything your app needs to run, 
from the operating system to the web server, runtime, and scaling infrastructure.

You just provide:
- Your code (as a ZIP or Docker image)
- A few configuration choices (runtime, instance type, scaling rules)
- Optional environment variables or database settings
Beanstalk handles the rest — including patching, provisioning, and even rolling updates.


When you deploy an app to Elastic Beanstalk, it automatically provisions:
System: EC2 instances with Amazon Linux or Windows OS
Runtime: Preconfigured environments for Node.js, Python, Java, .NET, PHP, Ruby, Go, Docker
Web Server: Nginx, Apache, IIS, or Passenger depending on the platform
Networking: VPC, security groups, load balancer, DNS (via Route 53 alias)
Scaling: Auto Scaling Group based on load
Monitoring: CloudWatch metrics, health checks, logs
Deployment: Upload ZIP or Docker image → Beanstalk deploys and manages it


If EC2 is like renting a raw server and configuring everything yourself,
Elastic Beanstalk is like handing AWS your app and saying: “Just make it run.”
