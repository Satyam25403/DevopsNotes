The AWS SDK for JavaScript (v3) is the official toolkit for integrating AWS services into your Node.js applications. 
It’s modular, TypeScript-friendly, and supports over 300 AWS services

Getting Started with AWS SDK in Node.js
1. Install the SDK
Instead of installing one big package, v3 lets you install only what you need:

npm install @aws-sdk/client-<servicename>

servicename can be anything like s3, dynamodb, lambda, ec2, etc.


2. Configure Credentials:
Use environment variables (recommended):
export AWS_ACCESS_KEY_ID=your-access-key
export AWS_SECRET_ACCESS_KEY=your-secret-key
export AWS_REGION=us-east-1


3. Example: Upload a File to S3
const { S3Client, PutObjectCommand } = require("@aws-sdk/client-s3");
const fs = require("fs");
const s3 = new S3Client({ region: "us-east-1" });
const uploadParams = {
  Bucket: "your-bucket-name",
  Key: "example.txt",
  Body: fs.createReadStream("example.txt"),
};
s3.send(new PutObjectCommand(uploadParams))
  .then(data => console.log("Upload success:", data))
  .catch(err => console.error("Upload error:", err));
