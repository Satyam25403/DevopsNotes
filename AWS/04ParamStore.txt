AWS Systems Manager(SSM) Parameter Store is a secure, scalable, and centralized service for managing configuration data and secrets. 
It’s perfect for storing things like database connection strings, API keys, environment variables, and other sensitive or dynamic values 
and retrieving them programmatically from your apps, scripts, or infrastructure.

similar to .env file but instead of storing locally, we store it in aws itself

SSM is the main service  => param store

🔐 What You Can Store
- Plain text values (e.g., NODE_ENV=production)
- Encrypted secrets (e.g., passwords, tokens) using AWS KMS
- Hierarchical paths (e.g., /myapp/dev/db-url) for organized access

🛠️ How to Use It with AWS CLI
✅ Store a Parameter
aws ssm put-parameter \
  --name "/myapp/dev/db-url" \
  --value "mongodb://localhost:27017" \
  --type "String"


For encrypted values:
aws ssm put-parameter \
  --name "/myapp/dev/db-password" \
  --value "supersecret" \
  --type "SecureString" \
  --key-id "alias/aws/ssm"


🔍 Retrieve a Parameter
aws ssm get-parameter \
  --name "/myapp/dev/db-url" \
  --with-decryption


Use --with-decryption only for SecureString parameters.

🧠 Why Use Parameter Store?
- ✅ Centralized config: Keep secrets and settings out of code
- 🔐 Secure: Encrypt with AWS KMS, control access with IAM
- 🧩 Integrated: Works with EC2, Lambda, ECS, CodeBuild, and more


🧪 Real-World Example
In a Node.js app using AWS SDK:
const { SSMClient, GetParameterCommand } = require("@aws-sdk/client-ssm");

const ssm = new SSMClient({ region: "us-east-1" });

const getParam = async () => {
  const command = new GetParameterCommand({
    Name: "/myapp/dev/db-url",
    WithDecryption: true,
  });
  const response = await ssm.send(command);
  console.log("DB URL:", response.Parameter.Value);
};
